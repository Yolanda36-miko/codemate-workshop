# CodeMate 智学工坊 技术手册

> 数据结构与算法个性化学习资源平台

---

## 1. 项目概述

CodeMate 智学工坊是一个面向《数据结构与算法》课程的个性化学习资源平台。系统以学习画像为基础，结合快速定制信息、课程资源库和大语言模型，为学习者提供贯穿学习全过程的个性化支持，包括学习资源生成、学习路径规划和智能辅导与闯关评估服务。

平台围绕以下核心理念构建：

- **单课程深度聚焦**：系统专注于《数据结构与算法》一门课程，覆盖复杂度分析、线性表、栈与队列、递归、树、图、排序查找、散列表、动态规划及综合项目实践十大模块。
- **学习画像驱动**：系统通过学习画像采集和快速定制信息机制获取学习者的基础水平、学习目标、困难点和偏好，并将这些信息用于资源生成、路径推荐和辅导评估的各个环节。
- **结构化资源生成**：系统支持图解讲解、代码示例、易错点、分层练习和项目案例五种资源类型，每种类型都有明确的生成模板和内容标准。
- **LLM Provider 可切换**：系统支持 mock 模式和 DeepSeek 两种 LLM Provider 模式，通过统一的 Provider 抽象层实现灵活切换。

---

## 2. 系统建设目标

CodeMate 智学工坊的建设目标如下：

| 目标 | 说明 |
|------|------|
| 聚焦《数据结构与算法》课程 | 平台以该课程为唯一内容范围，资源库、知识模块、评估题库均围绕数据结构与算法构建 |
| 构建数据结构知识模块体系 | 将课程内容组织为十大模块，用于资源生成、路径规划和评估的知识点映射 |
| 建立学习者画像与快速定制信息机制 | 支持长期画像（学习基础、认知风格、易错点、学习目标、资源偏好等）和临时快速定制信息（单次资源生成时补充）|
| 生成个性化学习资源 | 根据学习者画像和输入知识点，生成图解讲解、代码示例、易错点、分层练习、项目案例五类结构化资源卡片 |
| 支持资源包管理 | 学习者可将生成的资源加入个人资源包，与学习路径节点关联 |
| 支持学习路径规划 | 基于数据结构模块体系和学习者画像，生成个性化的学习顺序和节点内容 |
| 支持智能辅导和闯关评估 | 围绕数据结构知识点提供智能问答辅导和闯关式评测 |
| 支持 mock / DeepSeek 两种 LLM Provider 模式 | mock 模式用于开发调试和演示，DeepSeek 模式接入大语言模型提供真实 AI 生成能力 |

## 3. 功能模块说明

### 3.1 首页 Dashboard

**功能定位**：平台入口与全局导航页面，向学习者展示平台的核心功能和学习进度概览。

**主要功能**：
- 展示数据结构与算法课程概览和核心模块入口
- 提供学习画像、资源生成、学习路径、智能评估等功能的快捷导航
- 展示平台简介与使用引导

**用户操作流程**：进入首页后，学习者可浏览平台功能介绍，通过导航卡片或侧边栏进入各功能模块。

**与其他模块的关系**：Dashboard 作为导航枢纽，通过侧边栏和快捷入口连接所有功能模块。

---

### 3.2 学习画像 Profile

**功能定位**：学习画像采集与管理模块，是平台个性化的核心数据来源。

**主要功能**：
- 通过对话式交互采集学习者的先修基础、编程语言基础、学习困难、学习目标、资源偏好、认知风格、易错点和学习节奏等信息
- 形成结构化的学习画像数据
- 支持画像的持久化存储与更新
- 画像数据自动用于资源生成、路径推荐和智能辅导

**用户操作流程**：
1. 进入 Profile 页面
2. 与 CodeBuddy 智能助手进行对话
3. 逐步完成学习基础、学习目标、困难点和偏好的信息采集
4. 系统自动汇总生成学习画像
5. 画像信息可随时查看和更新

**与其他模块的关系**：Profile 模块是 ResourceGen（资源生成）、LearningPath（学习路径）、Assessment（智能评估）的数据基础，所有个性化功能均依赖学习画像。

---

### 3.3 数据结构模块中心 CourseCenter

**功能定位**：展示数据结构与算法十大知识模块的课程中心，帮助学习者了解课程体系全貌。

**主要功能**：
- 以卡片形式展示十大数据结构模块
- 每个模块展示模块名称、所属阶段（基础模块 / 核心模块 / 进阶模块）、核心知识点摘要
- 支持查看模块详情，包括先修要求、关联模块、典型困难和推荐学习资源类型
- 支持模块间的关联导航

**用户操作流程**：
1. 进入 CourseCenter 页面
2. 浏览十个数据结构模块
3. 点击模块卡片查看详细信息
4. 了解模块的知识点、前置要求和学习建议
5. 可跳转至资源生成页面学习特定模块内容

**与其他模块的关系**：CourseCenter 提供课程结构视图，为 ResourceGen 的资源生成提供知识点参照，为 LearningPath 的路径规划提供模块体系基础。

---

### 3.4 个性化资源生成 ResourceGen

**功能定位**：平台核心功能模块，根据学习者画像和输入主题生成个性化学习资源卡片。

**主要功能**：
- 支持学习者输入数据结构知识点作为学习主题
- 支持选择五种资源类型：图解讲解、代码示例、易错点、分层练习、项目案例
- 支持快速定制信息（学习基础、学习目标、编程语言、当前困难点、表达偏好），无需完整画像即可生成
- 支持 Python、C、C++、Java 四种编程语言的代码生成
- 调用 LLM 生成结构化资源卡片，每张卡片包含 highlight、steps、code、warning、practice、compare 等章节
- 支持将生成的资源加入个人资源包
- 支持展开/收起资源卡片的详细内容

**用户操作流程**：
1. 在资源生成页输入学习主题（如"二叉树前序遍历"）
2. 选择所需资源类型（可多选）
3. 选择编程语言或使用默认语言
4. 填写或确认快速定制信息（学习基础、学习目标、困难点、偏好）
5. 点击"生成个性化资源"
6. 系统展示生成的资源卡片，支持展开查看详细内容
7. 可将资源加入资源包，供学习路径使用

**与其他模块的关系**：ResourceGen 接收 Profile 的学习画像作为个性化依据，使用 CourseCenter 的模块体系进行知识点映射，生成的资源可加入资源包并与 LearningPath 的路径节点关联。

---

### 3.5 学习路径 LearningPath

**功能定位**：基于数据结构模块体系和学习者画像，为学习者规划和推荐个性化的学习顺序。

**主要功能**：
- 生成涵盖基础概念、线性结构、递归与树、图结构、排序与查找、动态规划、综合应用等阶段的学习路径
- 每个路径节点包含学习目标、预计时长、关联知识点、默认资源和匹配资源
- 路径节点按五阶段组织：基础概念 → 核心理解 → 代码实现 → 练习巩固 → 项目应用
- 支持查看节点详情和推荐资源
- 路径节点与资源包联动

**用户操作流程**：
1. 进入 LearningPath 页面
2. 系统根据学习画像自动生成个性化学习路径
3. 浏览路径时间线和各阶段节点
4. 点击节点查看学习目标、资源和任务说明
5. 可将资源包中的资源关联到路径节点

**与其他模块的关系**：LearningPath 使用 Profile 的学习画像进行个性化推荐，使用 CourseCenter 的模块体系组织学习顺序，与 ResourceGen 生成的资源包关联。

---

### 3.6 智能辅导与闯关评估 Assessment

**功能定位**：围绕数据结构与算法知识点提供智能辅导问答和闯关式评估。

**主要功能**：
- 支持学习者输入数据结构相关问题
- 系统结合知识点生成辅导回复，包含核心讲解、分步说明和代码示例
- 支持生成闯关题目进行知识掌握程度评估
- 闯关结果提供反馈和薄弱点分析
- 评估结果可辅助后续学习调整

**用户操作流程**：
1. 进入 Assessment 页面
2. 在学习问答区输入数据结构相关问题
3. 系统生成辅导回复
4. 可进入闯关模式，系统根据学习路径和知识点生成题目
5. 作答后获得即时反馈和评估结果

**与其他模块的关系**：Assessment 使用 Profile 的学习画像了解学习者的薄弱点，使用 CourseCenter 的知识点体系生成题目，评估结果可反馈至 Profile 更新画像。

---

### 3.7 右侧学习画像与资源包面板 RightPanel

**功能定位**：全局侧边栏中的右侧信息面板，展示当前学习画像摘要和个人资源包信息。

**主要功能**：
- 展示当前学习画像的关键维度（学习基础、学习目标、认知风格等）
- 展示个人资源包中已保存的资源数量和概要
- 提供快速跳转至 Profile 和 ResourceGen 的入口

**与其他模块的关系**：RightPanel 汇总展示 Profile 和 ResourceGen 的数据，在全局范围内提供学习状态概览。

## 4. 数据结构与算法课程模块体系

系统将《数据结构与算法》课程组织为十大知识模块，每个模块有明确的知识范围、典型困难点和推荐资源类型。

| 序号 | 模块名称 | 阶段 | 核心知识点 |
|------|---------|------|-----------|
| 1 | 复杂度分析 | 基础模块 | 时间复杂度、空间复杂度、大 O 表示法、渐进分析 |
| 2 | 线性表 | 基础模块 | 顺序表、单链表、双向链表、循环链表、插入删除操作 |
| 3 | 栈与队列 | 基础模块 | LIFO/FIFO 原理、循环队列、表达式求值、BFS 中的应用 |
| 4 | 递归与调用栈 | 核心模块 | 递归思想、调用栈机制、栈帧、终止条件、回溯算法 |
| 5 | 树与二叉树 | 核心模块 | 二叉树、四种遍历、二叉搜索树、满二叉树、完全二叉树 |
| 6 | 图结构与图算法 | 进阶模块 | DFS、BFS、Dijkstra 最短路径、拓扑排序、邻接表/邻接矩阵 |
| 7 | 排序与查找 | 核心模块 | 快速排序、归并排序、二分查找、排序算法稳定性对比 |
| 8 | 散列表 | 进阶模块 | 哈希函数、链地址法、开放定址法、负载因子、rehash |
| 9 | 动态规划入门 | 进阶模块 | 状态定义、转移方程、记忆化搜索、背包问题 |
| 10 | 综合项目实践 | 综合模块 | 表达式计算器、迷宫求解、路径规划器、数据结构综合应用 |

这些模块在系统中的作用：

- **资源生成**：当学习者输入知识点（如"二叉树前序遍历"）时，系统通过关键词匹配将其映射到对应模块（树与二叉树），从而确定生成内容的范围和相关标签。
- **学习路径**：路径规划以模块间的先修关系为基础，按基础模块 → 核心模块 → 进阶模块 → 综合模块的顺序组织学习节点。
- **智能评估**：评估题目和辅导回复按模块分类，系统根据学习者在各模块的表现识别薄弱点。
- **资源库组织**：后端资源库 `resource_library/data_structures/` 按模块子目录组织，每个模块包含讲解文档、代码示例、练习题、易错点分析等材料。

## 5. 个性化学习画像机制

### 5.1 学习画像采集内容

学习画像是平台个性化的核心数据来源，通过 Profile 模块的对话式交互采集。画像包含以下维度：

| 维度 | 说明 | 用途 |
|------|------|------|
| 先修基础 | 学习者的数学基础、编程基础和相关课程背景 | 调整内容难度和解释深度 |
| 编程语言基础 | 学习者熟悉 Python / C / C++ / Java 等语言 | 决定资源中的代码示例语言 |
| 当前学习困难 | 学习者感到困难的数据结构知识点 | 在资源中重点关注和解释 |
| 学习目标 | 概念理解 / 考试复习 / 刷题训练 / 项目实践 | 调整资源的侧重点和练习类型 |
| 资源偏好 | 图解优先 / 代码示例 / 分层练习 / 项目案例 | 决定推荐资源的表达形式 |
| 认知风格 | 图示优先、示例驱动等认知风格标签 | 影响资源的呈现方式 |
| 易错点 | 学习者在特定知识点上的常见错误模式 | 在资源中增加针对性的易错提醒 |
| 学习节奏 | 学习者的学习时间安排和进度偏好 | 调整路径节点的时间规划 |

### 5.2 快速定制信息机制

当学习者尚未完整建立学习画像时，可在资源生成页面通过"快速定制信息"面板补充以下信息：

- **学习基础**：基础薄弱 / 一般 / 较好
- **学习目标**：概念理解 / 考试复习 / 刷题训练 / 项目实践
- **编程语言**：Python / C / C++ / Java / 暂不确定
- **当前困难点**：可从预设的常见数据结构困难点中选择
- **表达偏好**：图解 / 代码示例 / 分层练习 / 项目案例

快速定制信息用于本次资源生成会话，其值保存在 sessionStorage 中，不影响持久化的学习画像。当学习者已建立完整画像时，快速定制信息可作为临时补充或覆盖。

## 6. 个性化资源生成机制

### 6.1 资源生成流程

个性化资源生成是平台的核心流程，其完整链路如下：

1. **用户输入**：学习者在 ResourceGen 页面输入数据结构知识点（如"快速排序为什么不稳定"），选择资源类型（可多选）、编程语言和快速定制信息。
2. **画像获取**：系统读取已有的学习画像（DB 或 localStorage），与当前快速定制信息合并，形成本次生成使用的完整画像。
3. **模块识别**：后端通过关键词匹配将用户输入映射到对应的数据结构模块（如"快速排序"映射到"排序与查找"）。
4. **资源库检索**：系统在资源库中搜索与当前模块和学习者画像标签匹配的参考资料，提取关键知识点作为 LLM prompt 的上下文。
5. **Prompt 构造**：系统将模块信息、画像数据、资源库摘要和资源类型要求填入 prompt 模板 `generate_resources.txt`。
6. **LLM 调用**：通过统一的 LLM Provider 接口调用大语言模型，传入构造好的 prompt。
7. **后处理**：对 LLM 返回的资源卡片进行后处理，包括代码语言校验与替换、文本字段清理、结构规范化。
8. **返回结果**：返回结构化的资源卡片数组，附带 generation_signature、normalized_module 等验证字段。
9. **前端展示**：前端以可展开卡片形式展示资源，学习者可查看详细内容并加入资源包。

### 6.2 五种资源类型及生成特点

| 资源类型 | 生成特点 | 核心章节 |
|---------|---------|---------|
| 图解讲解 | 突出概念拆解、步骤说明和图示化表达；包含 highlight、steps（3-5 步过程拆解）、compare（状态变化表）、warning（易错提醒）、practice（动手练习）| 核心要点 + 过程拆解 + 状态变化表 + 易错提醒 + 练习 |
| 代码示例 | 根据学习者选择的 Python / C / C++ / Java 生成完整可运行代码；包含逐行注释、复杂度分析和改写练习 | 代码要点 + 完整代码 + 逐段解释 + 易错点 + 改写练习 + 复杂度分析 |
| 易错点 | 总结常见误区和错误原因；每个错误配有具体数据例子和正确做法对比；包含纠错练习 | 错误描述 ×2 + 正确 vs 错误对比 + 根本原因 + 纠错练习 |
| 分层练习 | 提供基础、进阶、综合三层递进练习；每道题有具体输入输出示例和解题提示 | 练习目标 + 基础题 + 进阶题 + 综合题 + 解题提示 |
| 项目案例 | 提供真实应用场景和实现步骤；包含项目目标、场景需求、实现步骤、核心代码骨架、风险提示和扩展方向 | 项目目标 + 场景需求 + 实现步骤 + 核心设计 + 风险提示 + 扩展方向 |

### 6.3 资源卡片的个性化依据

每张生成的资源卡片包含 `personalized_reason` 字段，说明该资源为何适合当前学习者。个性化依据综合以下信息：

- 学习基础（调整内容深度和解释方式）
- 学习目标（调整侧重点：概念解释 / 考试重点 / 刷题模板 / 项目实践）
- 编程语言（决定代码示例的语言和语法）
- 当前困难点（在资源中增加针对性解释）
- 表达偏好（影响资源的呈现形式）

## 7. 学习路径规划机制

学习路径模块基于数据结构模块体系和学习者画像，为学习者生成个性化的学习顺序和节点内容。

### 7.1 路径阶段组织

路径节点按五个阶段组织，从前到后逐步递进：

| 阶段 | 说明 | 典型内容 |
|------|------|---------|
| 基础概念 | 建立数据结构的基本概念和术语体系 | 复杂度分析、线性表、栈与队列 |
| 核心理解 | 深入理解核心数据结构的工作原理 | 递归机制、二叉树结构与遍历 |
| 代码实现 | 将概念转化为可运行的代码 | 排序算法实现、遍历代码、图算法 |
| 练习巩固 | 通过分层练习巩固所学内容 | 专项练习、综合题、变式题 |
| 项目应用 | 综合运用多个模块知识完成项目 | 表达式计算器、路径规划器 |

### 7.2 路径节点结构

每个路径节点包含以下信息：

- **节点名称与所属课程**：标注节点对应的数据结构模块
- **学习目标**：本节点期望达到的学习效果
- **预计时长**：建议的学习时间
- **关键词**：节点关联的知识点标签
- **默认资源**：系统预设的该节点学习材料
- **匹配资源**：根据学习者画像和资源包自动匹配的资源
- **任务说明**：节点需要完成的具体学习任务
- **个性化推荐理由**：说明该节点为何出现在当前学习者的路径中

### 7.3 路径与资源的关联

学习路径节点与资源包联动。学习者在 ResourceGen 中生成的资源加入资源包后，可被自动匹配到对应的路径节点。路径节点同时包含系统默认资源和学习者个人资源包中的匹配资源，确保学习者在每个节点都有充分的学习材料。

## 8. 智能辅导与闯关评估机制

Assessment 模块围绕《数据结构与算法》课程提供智能辅导问答和闯关式评估功能。

### 8.1 智能辅导问答

学习者可在 Assessment 页面输入数据结构相关问题。系统根据以下信息生成辅导回复：

- 学习者的问题（提取关键词匹配数据结构知识点）
- 学习画像中的薄弱点和学习目标
- 学习路径中当前所处的节点和阶段

辅导回复包含核心概念讲解、分步说明和代码示例，帮助学习者在具体问题和知识点之间建立理解。

### 8.2 闯关评估

闯关评估功能生成与数据结构知识点相关的题目。系统结合用户输入的问题和当前学习路径节点确定题目范围和难度。

评估流程：

1. 系统生成包含题目、选项、正确答案和解析的闯关题
2. 学习者逐题作答
3. 系统对每道题给出即时反馈和知识点解析
4. 完成闯关后生成评估报告，包括得分、薄弱知识点和补救资源推荐

### 8.3 评估结果的应用

评估结果会反馈至学习画像系统，更新学习者的薄弱点信息，从而影响后续的资源生成和学习路径调整。

### 9.4 LLM Provider 层

系统通过统一的 `LLMProvider` 抽象基类实现 LLM Provider 的可切换性：

```python
class LLMProvider(ABC):
    def chat(self, messages: list[dict], **kwargs) -> ChatResponse: ...
    def chat_json(self, messages: list[dict], **kwargs) -> Optional[dict | list]: ...
```

支持的 Provider：

| Provider | 说明 |
|----------|------|
| MockProvider | 返回动态生成的数据结构与算法资源内容（非固定 mock 数据），适用于开发调试和演示环境 |
| DeepSeekProvider | 接入 DeepSeek API（OpenAI 兼容接口），提供真实 LLM 生成能力 |
| OpenAIProvider | 可扩展支持，接入 OpenAI 兼容 API |
| AnthropicProvider | 可扩展支持，接入 Anthropic Messages API |

**JSON 输出解析**：系统通过 `safe_parse_json()` 函数对 LLM 输出进行多层解析（直接解析 → 代码块提取 → 外层括号提取），确保从 LLM 响应中可靠提取结构化的 JSON 数据。

**Fallback 机制**：当 LLM 调用失败或返回无效数据时，系统自动降级到 `_build_fallback_resources()` 动态生成资源。Fallback 根据 topic、resource_types、language 和 quick_profile 生成与 LLM 模式一致结构的资源卡片。

### 12.2 资源库组织结构

资源库 `resource_library/data_structures/` 按数据结构模块分为 14 个主题子目录，每个子目录包含该主题的多种资源文件：

| 资源文件类型 | 格式 | 说明 |
|-------------|------|------|
| `*_explainer.md` | Markdown | 概念讲解文档 |
| `*_diagram.md` | Markdown | 图解说明 |
| `*_code.md` / `*_python_code.md` | Markdown | 代码示例 |
| `*_pitfalls.md` | Markdown | 易错点分析 |
| `*_exercises.json` | JSON | 练习题集 |
| `*_project.md` | Markdown | 项目案例 |
| `*_mindmap.md` | Markdown | 知识体系思维导图 |
| `*_reading.md` | Markdown | 拓展阅读材料 |
| `*_comparison.md` | Markdown | 算法对比分析 |

### 12.3 资源库索引

`index.json` 以统一格式管理所有资源文件的元数据。每条记录包含：

- `id`：资源唯一标识
- `title`：资源标题
- `type`：资源类型（图解讲解、代码示例、易错点、分层练习、项目案例等）
- `courseCode`：课程代码（`data_structures`）
- `topicCode`：主题代码（如 `binary_tree_traversal`）
- `difficulty`：难度等级
- `language`：编程语言（如有）
- `tags`：标签列表（用于搜索和匹配）
- `file`：相对路径指向资源文件
- `summary`：资源摘要

资源库在资源生成流程中通过 `_search_library()` 函数检索，检索结果作为参考资料嵌入 LLM prompt 的上下文中。

## 13. 核心业务流程

### 流程一：学习画像生成流程

```
用户进入 Profile 页面
    │
    ├─→ 与 CodeBuddy 助手开始对话
    │     ├─ 系统询问先修基础和学习背景
    │     ├─ 系统询问当前学习困难
    │     ├─ 系统询问学习目标和偏好
    │     └─ 系统询问编程语言和资源偏好
    │
    ├─→ 系统提取对话中的结构化字段
    │     ├─ knowledge_base_score（基础知识评分）
    │     ├─ practice_ability_score（实践能力评分）
    │     ├─ cognitive_styles（认知风格标签）
    │     ├─ error_patterns（易错点标签）
    │     ├─ learning_goals（学习目标标签）
    │     └─ resource_preferences（资源偏好标签）
    │
    ├─→ 生成画像摘要 (profile_summary)
    │
    └─→ 画像持久化至数据库
          └─→ 画像用于 ResourceGen、LearningPath、Assessment
```

### 流程二：个性化资源生成流程

```
用户进入 ResourceGen 页面
    │
    ├─→ 输入数据结构知识点（如"二叉树的三种遍历"）
    ├─→ 选择资源类型（图解讲解、代码示例、易错点等）
    ├─→ 选择编程语言（Python / C / C++ / Java）
    ├─→ 填写/确认快速定制信息
    │     ├─ 学习基础（薄弱 / 一般 / 较好）
    │     ├─ 学习目标（理解 / 考试 / 刷题 / 实践）
    │     └─ 当前困难点（可选）
    │
    ├─→ 点击"生成个性化资源"
    │
    ├─→ 后端处理流程：
    │     ├─ 1. 合并学习画像与快速定制信息
    │     ├─ 2. 关键词匹配识别数据结构模块
    │     ├─ 3. 检索资源库获取匹配材料
    │     ├─ 4. 构造 LLM Prompt（含模块、画像、资源库摘要）
    │     ├─ 5. 调用 LLM Provider 生成资源
    │     ├─ 6. 后处理：代码语言校验与替换、文本清理
    │     └─ 7. 返回结构化资源卡片数组
    │
    └─→ 前端展示资源卡片
          ├─ 卡片支持展开/收起查看详细章节
          ├─ 每张卡片含 personalized_reason（个性化推荐理由）
          └─ 用户可将卡片加入个人资源包
```

### 流程三：学习路径与评估流程

```
系统根据学习画像生成学习路径
    │
    ├─→ 路径按五阶段组织：基础概念 → 核心理解 → 代码实现 → 练习巩固 → 项目应用
    │
    ├─→ 每个路径节点包含：
    │     ├─ 学习目标、预计时长、关键词
    │     ├─ 系统默认资源
    │     └─ 个人资源包匹配资源
    │
    ├─→ 用户查看路径时间线，点击节点查看详情
    │
    ├─→ Assessment 模块提供辅导与评估：
    │     ├─ 用户输入数据结构相关问题
    │     ├─ 系统结合画像和路径节点生成辅导回复
    │     ├─ 用户可进入闯关模式
    │     └─ 系统生成题目 → 用户作答 → 即时反馈 → 评估报告
    │
    └─→ 评估结果反馈至画像，更新薄弱点和学习建议
```

## 15. 系统使用流程

以一名学习者首次使用 CodeMate 智学工坊的完整流程为例：

1. **进入首页** — 学习者打开平台，Dashboard 展示数据结构与算法课程概览和功能导航。

2. **查看数据结构模块** — 在 CourseCenter 页面浏览十大数据结构模块，了解课程体系全貌和各模块的知识点范围。

3. **建立学习画像** — 进入 Profile 页面，与 CodeBuddy 助手对话，逐步完成学习基础、学习目标、困难点和偏好的信息采集。系统自动生成结构化的学习画像。

4. **输入学习主题** — 在 ResourceGen 页面输入想要学习的数据结构知识点，如"快速排序的 partition 过程"。

5. **选择资源类型** — 勾选所需的资源类型，例如同时选择"图解讲解"和"代码示例"。

6. **填写快速定制信息** — 确认或调整学习基础、学习目标和编程语言。如果已建立完整画像，此步骤可跳过。

7. **生成个性化资源** — 点击生成按钮，系统根据画像和输入生成结构化资源卡片。图解讲解卡片展示 partition 的步骤拆解和状态变化表，代码示例卡片展示所选语言的完整可运行代码。

8. **将资源加入资源包** — 浏览生成的资源卡片，展开查看详细内容，将有用的资源加入个人资源包。

9. **查看学习路径** — 进入 LearningPath 页面，查看系统根据画像生成的个性化学习路径。路径节点自动关联了个人资源包中的匹配资源。

10. **进行辅导与闯关练习** — 在 Assessment 页面输入学习中遇到的问题，获得智能辅导回复。进入闯关模式检验知识掌握程度，根据评估反馈调整后续学习重点。

## 16. 技术特点

| 特点 | 说明 |
|------|------|
| 单课程深度聚焦 | 系统围绕《数据结构与算法》一门课程构建完整的知识模块体系、资源库和评估题库 |
| 学习画像驱动 | 画像覆盖 8 个维度（基础、语言、困难、目标、偏好、认知风格、易错点、节奏），深度参与资源生成、路径推荐和辅导评估 |
| 资源类型可控 | 支持图解讲解、代码示例、易错点、分层练习、项目案例五种资源类型，每种有明确的生成模板和内容标准 |
| 快速定制信息机制 | 无需完整画像即可通过快速定制信息生成个性化资源，降低使用门槛 |
| 结构化资源卡片 | 资源以 section 数组形式组织（highlight、steps、code、warning、practice、compare 等），前端按 kind 类型差异化渲染 |
| 数据结构资源库支撑 | 资源库按模块组织，包含讲解文档、代码示例、练习题、易错点分析等材料，为 LLM 生成提供领域知识上下文 |
| LLM Provider 可切换 | 统一的 Provider 抽象层，支持 mock 和 DeepSeek，可扩展 OpenAI 和 Anthropic |
| 多语言代码生成 | 资源生成支持 Python、C、C++、Java 四种编程语言，后处理流程确保代码语言与用户选择一致 |
| 学习路径与评估联动 | 路径节点关联资源包资源，评估结果反馈至画像更新，形成学习闭环 |
| 组件化前端架构 | 前端采用页面-组件二级结构，27 个功能组件按 7 个功能域组织，组件职责清晰 |
