# 复杂度分析概念讲解

## 适合对象
正在学习数据结构与算法，需要理解算法效率度量方式的学生。

## 核心概念

### 时间复杂度
- **大O表示法**：描述算法执行时间随输入规模增长的趋势，忽略常数和低阶项。
- **常见复杂度**：O(1) 常数、O(log n) 对数、O(n) 线性、O(n log n) 线性对数、O(n²) 平方、O(2ⁿ) 指数。
- **最好/最坏/平均情况**：同一个算法对不同输入的性能差异。

### 空间复杂度
- 算法运行过程中额外占用的内存空间。
- 包含：变量空间、递归调用栈空间、数据结构空间。

### 易错点
1. 嵌套循环复杂度判断：两层循环不一定是 O(n²)，要看循环变量的增长方式。
2. 递归复杂度：需考虑递归树的深度和每层的工作量。
3. 忽略常数操作：例如字符串拼接在循环中可能是 O(n²) 而非 O(n)。

### 学习建议
从简单循环开始分析，逐步过渡到嵌套循环和递归。多用具体代码实例对比。
