# 栈与队列的典型应用图解讲解

## 核心概念

### 栈（Stack）

栈是一种**后进先出（LIFO, Last In First Out）**的数据结构，像一叠盘子，只能从顶部取放。

**核心操作**：

| 操作 | 说明 |
|------|------|
| push | 将元素压入栈顶 |
| pop | 弹出栈顶元素 |
| top | 获取栈顶元素（不弹出） |
| isEmpty | 判断栈是否为空 |

**栈的特点**：
- 只能访问栈顶元素
- 插入和删除都在栈顶进行
- 操作时间复杂度都是 O(1)

### 队列（Queue）

队列是一种**先进先出（FIFO, First In First Out）**的数据结构，像排队买票，先到先服务。

**核心操作**：

| 操作 | 说明 |
|------|------|
| enqueue | 将元素加入队尾 |
| dequeue | 移除队首元素 |
| front | 获取队首元素（不移除） |
| isEmpty | 判断队列是否为空 |

**队列的特点**：
- 队首是最先加入的元素，队尾是最后加入的元素
- 插入在队尾，删除在队首
- 操作时间复杂度都是 O(1)

### 栈与队列的关键区别

| 对比项 | 栈 | 队列 |
|--------|-----|------|
| 访问顺序 | 后进先出（LIFO） | 先进先出（FIFO） |
| 插入位置 | 栈顶 | 队尾 |
| 删除位置 | 栈顶 | 队首 |
| 典型应用 | 括号匹配、函数调用、回文判断 | 任务调度、消息队列、广度优先搜索 |

## 过程拆解

### 栈的应用 — 括号匹配

**问题描述**：给定表达式 `( [ { } ] )`，用栈检查括号是否匹配。

**算法思路**：
1. 遇到左括号 `(` `[` `{` 时，将其压入栈。
2. 遇到右括号 `)` `]` `}` 时，检查栈顶是否是对应的左括号：
   - 如果是，弹出栈顶；
   - 如果不是或栈为空，则匹配失败。
3. 遍历结束后，如果栈为空，则括号匹配成功；否则失败。

**具体步骤**：

```
表达式: ( [ { } ] )

步骤1: 遇到 '(', 压入栈 → 栈: [ ( ]
步骤2: 遇到 '[', 压入栈 → 栈: [ (, [ ]
步骤3: 遇到 '{', 压入栈 → 栈: [ (, [, { ]
步骤4: 遇到 '}', 检查栈顶是 '{', 匹配成功, 弹出 → 栈: [ (, [ ]
步骤5: 遇到 ']', 检查栈顶是 '[', 匹配成功, 弹出 → 栈: [ ( ]
步骤6: 遇到 ')', 检查栈顶是 '(', 匹配成功, 弹出 → 栈: [ ]
步骤7: 遍历结束, 栈为空 → 匹配成功!
```

### 队列的应用 — 模拟排队

**问题描述**：模拟一个简单的队列，依次执行以下操作：enqueue(1), enqueue(2), enqueue(3), dequeue(), enqueue(4)。

**具体步骤**：

```
初始状态: 队列为空

步骤1: enqueue(1) → 队列: [1]
步骤2: enqueue(2) → 队列: [1, 2]
步骤3: enqueue(3) → 队列: [1, 2, 3]
步骤4: dequeue() → 移除队首 1, 队列: [2, 3]
步骤5: enqueue(4) → 队列: [2, 3, 4]

最终状态: 队列: [2, 3, 4]
```

## 小规模具体例子

### 栈的应用 — 回文判断

**问题描述**：判断字符串 "racecar" 是否为回文。

**算法思路**：
1. 将字符串的前半部分字符压入栈。
2. 对于后半部分字符，依次与栈顶字符比较：
   - 如果相等，弹出栈顶；
   - 如果不等，不是回文。
3. 如果栈为空，则是回文。

**具体步骤**（字符串长度为 7，前 3 个字符入栈）：

```
字符串: r a c e c a r

步骤1: push 'r' → 栈: [r]
步骤2: push 'a' → 栈: [r, a]
步骤3: push 'c' → 栈: [r, a, c]
步骤4: 中间字符 'e'，跳过
步骤5: 比较 'c' 与栈顶 'c' → 相等, pop → 栈: [r, a]
步骤6: 比较 'a' 与栈顶 'a' → 相等, pop → 栈: [r]
步骤7: 比较 'r' 与栈顶 'r' → 相等, pop → 栈: [ ]

栈为空 → "racecar" 是回文!
```

**状态变化表**：

| 步骤 | 当前字符 | 栈状态 | 操作 | 说明 |
|------|---------|--------|------|------|
| 1 | r | [r] | push | 前半部分入栈 |
| 2 | a | [r, a] | push | 前半部分入栈 |
| 3 | c | [r, a, c] | push | 前半部分入栈 |
| 4 | e | [r, a, c] | — | 中间字符跳过 |
| 5 | c | [r, a] | pop | 匹配成功 |
| 6 | a | [r] | pop | 匹配成功 |
| 7 | r | [ ] | pop | 匹配成功 |

### 队列的应用 — 打印机任务队列

**问题描述**：模拟打印机任务队列，多个任务按提交顺序排队等待打印。

**任务序列**：
- 任务 A：打印文档1（需2秒）
- 任务 B：打印文档2（需3秒）
- 任务 C：打印文档3（需1秒）

**执行过程**：

```
时间线:

t=0: 任务 A 提交 → 队列: [A]
t=1: 任务 B 提交 → 队列: [A, B]
t=2: 任务 A 完成, 开始打印 B → 队列: [B]
t=3: 任务 C 提交 → 队列: [B, C]
t=5: 任务 B 完成, 开始打印 C → 队列: [C]
t=6: 任务 C 完成 → 队列: [ ]

执行顺序: A → B → C (先进先出)
```

**状态变化表**：

| 时间 | 事件 | 队列状态 | 正在打印 |
|------|------|---------|---------|
| t=0 | A 提交 | [A] | — |
| t=1 | B 提交 | [A, B] | A |
| t=2 | A 完成 | [B] | B |
| t=3 | C 提交 | [B, C] | B |
| t=5 | B 完成 | [C] | C |
| t=6 | C 完成 | [ ] | — |

## 易错提醒

### 错误一：栈操作时忘记判空

**错误代码**：

```cpp
int top = stack.top();  // 栈可能为空!
stack.pop();            // 栈可能为空!
```

**错误后果**：运行时错误（Segmentation Fault 或异常）。

**正确做法**：

```cpp
if (!stack.empty()) {
    int top = stack.top();
    stack.pop();
}
```

### 错误二：括号匹配中混淆括号类型

**错误代码**：

```cpp
// 错误：只检查是否是左括号，不检查类型
if (current == ')' || current == ']' || current == '}') {
    if (!stack.empty() && stack.top() != current) {  // 错误的判断
        return false;
    }
}
```

**错误后果**：`( { } ] )` 会被错误判断为匹配成功。

**正确做法**：

```cpp
bool isMatching(char left, char right) {
    return (left == '(' && right == ')') ||
           (left == '[' && right == ']') ||
           (left == '{' && right == '}');
}
```

### 错误三：队列操作中混淆队首和队尾

**错误代码**：

```cpp
// 错误：从队尾删除元素
void dequeue() {
    queue.pop_back();  // 破坏了 FIFO 顺序!
}
```

**错误后果**：最后加入的元素被删除，违反先进先出原则。

**正确做法**：

```cpp
void dequeue() {
    queue.pop_front();  // 从队首删除
}
```

### 错误四：循环队列边界错误

**错误代码**：

```cpp
// 错误：front 和 rear 的更新逻辑
void enqueue(int x) {
    rear = (rear + 1) % capacity;
    data[rear] = x;
}
```

**错误后果**：当队列满时，rear 会覆盖 front 指向的元素。

**正确做法**：

```cpp
bool isFull() {
    return (rear + 1) % capacity == front;
}

void enqueue(int x) {
    if (isFull()) {
        // 队列已满，需要扩容
        return;
    }
    rear = (rear + 1) % capacity;
    data[rear] = x;
}
```

### 错误五：结构选型错误

**错误理解**：将栈用于"先到先服务"的场景，或将队列用于"后到先服务"的场景。

**示例**：
- **错误**：用栈来处理排队买票的问题（先到的人反而后买到票）
- **错误**：用队列来实现撤销功能（最新的操作反而最后撤销）

**正确选型**：
- 需要"先到先服务"时，使用队列
- 需要"后到先服务"时，使用栈

### 练习三

**题目描述**：判断以下说法是否正确，并说明理由："栈和队列都是线性结构，所以它们的元素访问方式是一样的。"

**答案要点**：

**不正确**。

**理由**：

1. **相同点**：栈和队列都是线性结构，元素之间都有线性顺序关系。

2. **不同点**：
   - **栈**：只能访问栈顶元素，是"后进先出"（LIFO）
   - **队列**：只能访问队首元素，是"先进先出"（FIFO）

3. **具体差异**：
   - 栈的插入和删除都在同一端（栈顶）
   - 队列的插入在队尾，删除在队首

**对比表**：

| 操作 | 栈 | 队列 |
|------|-----|------|
| 插入位置 | 栈顶 | 队尾 |
| 删除位置 | 栈顶 | 队首 |
| 访问位置 | 栈顶 | 队首 |
| 顺序 | LIFO | FIFO |
