# 栈与队列概念讲解

## 适合对象
学习栈与队列的数据结构学生，需要理解 LIFO/FIFO 及经典应用。

## 核心概念

### 栈（Stack）— LIFO
- 后进先出，只在一端操作（栈顶）。
- 经典应用：函数调用栈、表达式求值、括号匹配、DFS 回溯。
- 可用数组或链表实现。

### 队列（Queue）— FIFO
- 先进先出，一端入队一端出队。
- 经典应用：BFS 遍历、任务调度、消息队列、缓存。
- 循环队列解决数组实现的假溢出问题。

### 易错点
1. 栈空/栈满的边界判断。
2. 循环队列的判空判满条件（空：front==rear，满：(rear+1)%size==front）。
3. 中缀转后缀表达式时运算符优先级的处理。

### 学习建议
从基本操作入手，通过表达式求值和括号匹配等经典问题加深理解，再尝试 BFS 中的队列应用。
