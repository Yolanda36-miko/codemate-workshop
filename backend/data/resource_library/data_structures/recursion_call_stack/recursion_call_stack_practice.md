## 可选答案要点

### 基础题一答案

**调用过程**：

```
sum(3) = 3 + sum(2)
sum(2) = 2 + sum(1)
sum(1) = 1 + sum(0)
sum(0) = 0  （终止条件）
```

**回溯计算**：

```
sum(0) = 0
sum(1) = 1 + 0 = 1
sum(2) = 2 + 1 = 3
sum(3) = 3 + 3 = 6
```

**最终结果**：6

### 基础题二答案

**判断**：

对于非负整数 n，函数正确。但对于负数 n，函数会无限递归。

**原因**：

当 n 为负数时，`n-1` 会越来越小（越来越负），永远不会等于 0，导致无限递归和栈溢出。

**修改方案**：

```cpp
int power(int x, int n) {
    if (n < 0) {
        // 处理负数情况
        return 1 / power(x, -n);
    }
    if (n == 0) return 1;
    return x * power(x, n-1);
}
```

### 进阶题一答案

**完整代码**：

```cpp
int fib(int n) {
    if (n == 0) return 0;  // 终止条件1
    if (n == 1) return 1;  // 终止条件2
    return fib(n-1) + fib(n-2);  // 递归步
}
```

**n=40 慢的原因**：

纯递归版本有大量重复计算，时间复杂度为 O(2^n)。

**优化方法**：

使用记忆化或动态规划：

```cpp
int fib(int n, vector<int>& memo) {
    if (n == 0) return 0;
    if (n == 1) return 1;
    if (memo[n] != -1) return memo[n];
    memo[n] = fib(n-1, memo) + fib(n-2, memo);
    return memo[n];
}
```

### 进阶题二答案

**调用树**：

```
          fib(4)
         /      \
    fib(3)      fib(2)
    /   \        /   \
 fib(2) fib(1) fib(1) fib(0)
 /  \
fib(1) fib(0)
```

**调用次数统计**：

| 函数调用 | 次数 |
|----------|------|
| fib(4) | 1 |
| fib(3) | 1 |
| fib(2) | 2 |
| fib(1) | 3 |
| fib(0) | 2 |
| **总计** | **9** |

**结果**：共调用 9 次。

### 进阶题三答案

**调用过程**：

```
gcd(100, 10) → gcd(10, 0) → 返回 10
```

**递归深度**：2（包括 gcd(100,10) 和 gcd(10,0)）

**空间复杂度**：

一般情况下，欧几里得算法的递归深度为 O(log(min(a,b)))，空间复杂度为 O(log(min(a,b)))。

### 综合题一答案

**递归函数**：

```cpp
int arraySum(vector<int>& arr, int index) {
    if (index == arr.size()) return 0;
    return arr[index] + arraySum(arr, index + 1);
}
```

**调用栈深度**：数组长度 + 1

**空间复杂度**：O(n)，其中 n 是数组长度

**大数组问题**：

当数组长度为 100000 时，递归深度为 100001，可能超过系统栈限制，导致栈溢出。

**解决方案**：

使用迭代版本：

```cpp
int arraySumIterative(vector<int>& arr) {
    int sum = 0;
    for (int num : arr) {
        sum += num;
    }
    return sum;
}
```

### 综合题二答案

**递归算法**：

```
hanoi(n, from, to, aux):
    if n == 1:
        直接将圆盘从 from 移到 to
        return
    
    hanoi(n-1, from, aux, to)    // 将 n-1 个圆盘从 from 移到 aux
    直接将第 n 个圆盘从 from 移到 to
    hanoi(n-1, aux, to, from)    // 将 n-1 个圆盘从 aux 移到 to
```

**调用次数**：

对于 `hanoi(n)`，调用次数 = 2^n - 1

`hanoi(4)` = 2^4 - 1 = 15 次

**递归深度**：

每次递归调用 n 减少 1，从 n 到 1 需要 n 层调用，所以递归深度 = n。

**空间复杂度**：

O(n)，递归调用栈的最大深度为 n。
