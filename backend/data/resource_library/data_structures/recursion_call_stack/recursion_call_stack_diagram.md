## 图解示例 1：斐波那契数列

```python
def fib(n):
    if n <= 1:
        return n
    return fib(n - 1) + fib(n - 2)
```

### fib(4) 的递归树

```

             /     \      /    \
        fib(2)   fib(1) fib(1) fib(0)
       /     \

```

## 图解示例 2：归并排序的调用栈

```python
def merge_sort(arr):
    if len(arr) <= 1:
        return arr
    mid = len(arr) // 2
    left = merge_sort(arr[:mid])
    right = merge_sort(arr[mid:])
    return merge(left, right)
```

### 对 [38, 27, 43, 3] 执行 merge_sort 的递归树

```
              merge_sort([38,27,43,3])
              /                      \
    merge_sort([38,27])        merge_sort([43,3])
       /          \               /          \
merge_sort([38]) merge_sort([27]) merge_sort([43]) merge_sort([3])
     |               |               |               |
   [38]            [27]            [43]            [3]
     \              /                \              /
    merge([38],[27])                merge([43],[3])
         |                               |
      [27,38]                         [3,43]
         \                             /
          merge([27,38], [3,43])
                   |
            [3, 27, 38, 43]
```

### 关键观察

1. **分治递归的栈深度**：每次对半分割，栈深度为 O(log n)
2. **先递推到底**：一直分割到单个元素才停止
3. **回溯时合并**：真正的排序发生在回溯阶段

## 栈帧内部结构

以 `factorial(3)` 调用 `factorial(2)` 为例：

```
┌─── factorial(2) 的栈帧 ───┐
│ 返回地址: factorial(3) L3  │  ← 函数执行完回到哪里
│ 参数 n: 2                  │  ← 局部参数
│ 局部变量: 无               │
│ 返回值预留: ?              │  ← 等待 factorial(1) 返回
├───────────────────────────┤
│ 调用者栈帧的 %rbp 保存值    │  ← 恢复上一帧的基指针
└───────────────────────────┘
```

## 易混淆点

### "递推时不做计算" vs "回溯时才计算"

```python
# 递推阶段：只压栈，不计算
# 回溯阶段：弹栈后执行 return 后面的表达式

def sum_list(arr):
    if not arr:
        return 0
    # sum_list(arr[1:]) 先执行（递推）
    # arr[0] + 结果 后执行（回溯）
    return arr[0] + sum_list(arr[1:])
```
