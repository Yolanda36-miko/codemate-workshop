## 核心概念

### 递归的两个阶段

递归的执行过程分为两个阶段：

1. **递推阶段（Forward/Unwinding）**：函数不断调用自身，将当前状态压入调用栈，问题规模逐步缩小。
2. **回溯阶段（Backward/Rewinding）**：到达终止条件后，从栈顶依次弹出栈帧，逐层返回结果。

### 调用栈与栈帧

每次函数调用都会在调用栈上创建一个**栈帧**，包含：
- **返回地址**：函数执行完毕后应返回的位置
- **局部变量**：当前函数调用中的参数和局部变量
- **返回值空间**：预留用于存放返回结果

```
factorial(3) 调用过程：

调用栈（栈顶在右）:
[main] → [fact(3)] → [fact(2)] → [fact(1)]

fact(1) 到达出口，返回 1:
[main] → [fact(3)] → [fact(2)]  ← 收到 1

fact(2) 计算 2 * 1 = 2，返回 2:
[main] → [fact(3)]  ← 收到 2

fact(3) 计算 3 * 2 = 6，返回 6:
[main]  ← 收到 6
```

### 完整示例：factorial(3)

```python
def factorial(n):
    if n <= 1:          # 出口条件
        return 1
    return n * factorial(n - 1)
```

| 步骤 | 调用 | n 的值 | 栈深度 | 操作 | 返回值 |
|------|------|--------|--------|------|--------|
| 1 | factorial(3) | 3 | 1 | 压栈，等待 factorial(2) | — |
| 2 | factorial(2) | 2 | 2 | 压栈，等待 factorial(1) | — |
| 3 | factorial(1) | 1 | 3 | 到达出口 | 1 |
| 4 | 回到 factorial(2) | 2 | 2 | 弹栈，计算 2 * 1 | 2 |
| 5 | 回到 factorial(3) | 3 | 1 | 弹栈，计算 3 * 2 | 6 |

### 递归中的"保存现场"

每次递归调用时，当前函数的状态（参数、局部变量、执行位置）被保存在栈帧中。回溯时恢复这些状态继续执行。

```python
def countdown(n):
    if n == 0:
        print("发射!")
        return
    print(f"倒计时: {n}")
    countdown(n - 1)
    print(f"倒计时 {n} 结束")  # 回溯时执行

# 输出:
# 倒计时: 3
# 倒计时: 2
# 倒计时: 1
# 发射!
# 倒计时 1 结束   ← 回溯阶段
# 倒计时 2 结束
# 倒计时 3 结束
```

### 递归深度限制

Python 默认递归深度限制约为 1000：

```python
import sys
print(sys.getrecursionlimit())  # 通常为 1000

# 对于需要更深递归的场景：
sys.setrecursionlimit(2000)
```

## 常见错误

1. 终止条件永不满足导致无限递归
2. 递推阶段做了修改但回溯阶段未恢复（回溯问题）
3. 递归过深导致栈溢出
