# 二叉树遍历图解讲义

## 适用对象
适合正在学习数据结构与算法，希望通过图示理解二叉树遍历（前序、中序、后序）的学生。

## 学习目标
- 理解二叉树的定义和基本术语
- 掌握前序、中序、后序遍历的访问顺序
- 能够手动写出简单二叉树的三种遍历结果

## 核心概念
二叉树是一种树形数据结构，每个节点最多有两个子节点：左子节点和右子节点。根节点是树的顶端节点。遍历是按照某种顺序访问树中所有节点的过程。

## 分步骤讲解
1. 前序遍历（根左右）：先访问根节点，然后递归遍历左子树，最后递归遍历右子树。
2. 中序遍历（左根右）：先递归遍历左子树，然后访问根节点，最后递归遍历右子树。
3. 后序遍历（左右根）：先递归遍历左子树，然后递归遍历右子树，最后访问根节点。

示例二叉树：
     A
   /   \
  B     C
 / \     \
D   E     F

遍历结果：
- 前序：A, B, D, E, C, F
- 中序：D, B, E, A, C, F
- 后序：D, E, B, F, C, A

## 代码或示例
Python 伪代码：
def preorder(node):
    if node:
        visit(node)
        preorder(node.left)
        preorder(node.right)

## 常见错误
- 混淆遍历顺序：记住根节点的访问位置是关键。
- 忘记递归出口：必须检查 node 是否为 None。

## 自我检查
1. 前序遍历的第一个节点是什么？ 答案：根节点
2. 后序遍历的最后一个节点是什么？ 答案：根节点
