# 线性表概念讲解

## 适合对象
学习数据结构与算法中的线性表模块，需要理解顺序表与链表的差异。

## 核心概念

### 顺序表（数组实现）
- 连续内存存储，支持随机访问 O(1)。
- 插入/删除需移动元素，平均 O(n)。
- 适合：频繁查询、尾部增删的场景。

### 链表
- 节点分散存储，通过指针链接，不支持随机访问。
- 单链表、双向链表、循环链表的区别和适用场景。
- 插入/删除只需修改指针 O(1)，但查找需要遍历 O(n)。

### 易错点
1. 链表头结点和尾结点的边界处理（空链表、单节点链表）。
2. 插入/删除时指针修改顺序不当导致链表断裂。
3. 双向链表的 prev/next 指针同步更新。

### 学习建议
多画图理解指针指向变化，先实现单链表基本操作再扩展。
