## 每题提示

### 基础题一提示

记住三种遍历顺序的核心：
- 前序：根在最前
- 中序：根在中间
- 后序：根在最后

### 基础题二提示

根据前序遍历"根-左-右"的特点，第一个元素是根，接下来是左子树的前序序列，再是右子树的前序序列。

### 进阶题一提示

递归函数需要：终止条件、访问当前节点、递归左子树、递归右子树。

### 进阶题二提示

递归的空间复杂度取决于递归调用栈的深度，即树的高度。

### 进阶题三提示

栈是"后进先出"，要保证左子节点先被访问，需要先压入右子节点。

### 综合题一提示

二叉搜索树的性质：左子树所有节点值 < 根节点值 < 右子树所有节点值。前序遍历的第一个元素是根。

### 综合题二提示

前序序列确定根节点，中序序列确定左右子树的范围。

## 可选答案要点

### 基础题一答案

- **前序**：1, 2, 4, 5, 3
- **中序**：4, 2, 5, 1, 3
- **后序**：4, 5, 2, 3, 1

### 基础题二答案

**选项 A** 正确。前序序列 `A B D E C F` 对应：
- A 是根
- BDE 是左子树的前序（B是根，D和E是B的左右子）
- CF 是右子树的前序（C是根，F是C的右子）

### 进阶题一答案

```cpp
void preorder(TreeNode* root) {
    if (root == nullptr) return;  // 空缺1
    cout << root->val << " ";     // 空缺2
    preorder(root->left);
    preorder(root->right);        // 空缺3
}
```

### 进阶题二答案

1. **完全二叉树**：空间复杂度 O(log n)，因为树的高度 h = O(log n)
2. **链状树**：空间复杂度 O(n)，因为树的高度 h = n（等于节点数）

### 进阶题三答案

**错误步骤**：第6步压入节点5。

**原因**：根据题目中的树结构 `1(2(4),3)`，节点2只有左子节点4，没有右子节点5。第6步应该跳过压入右子节点的操作。

### 综合题一答案

**判断思路**：
1. 使用一个栈来维护路径上的节点
2. 使用一个变量记录当前允许的最小值（初始为负无穷）
3. 遍历前序序列：
   - 如果当前值小于最小值，返回 false
   - 弹出栈中所有小于当前值的节点，更新最小值
   - 将当前值压入栈
4. 返回 true

**关键代码逻辑**：

```cpp
bool isValidBSTPreorder(vector<int>& preorder) {
    stack<int> st;
    int minVal = INT_MIN;
    for (int val : preorder) {
        if (val < minVal) return false;
        while (!st.empty() && st.top() < val) {
            minVal = st.top();
            st.pop();
        }
        st.push(val);
    }
    return true;
}
```

### 综合题二答案

**重建步骤**：
1. 前序第一个元素 1 是根节点
2. 中序中 1 的左边 `4 2 5` 是左子树，右边 `6 3` 是右子树
3. 递归重建左子树（前序：`2 4 5`，中序：`4 2 5`）
4. 递归重建右子树（前序：`3 6`，中序：`6 3`）

**重建后的树结构**：

```
    1
   / \
  2   3
 /   /
4   6
 \
  5
```

**验证**：
- 前序：1, 2, 4, 5, 3, 6 ✓
- 中序：4, 2, 5, 1, 6, 3 ✓
