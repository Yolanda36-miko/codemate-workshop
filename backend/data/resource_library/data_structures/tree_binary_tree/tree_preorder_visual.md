# 二叉树前序遍历图解讲解

## 核心概念

前序遍历是二叉树深度优先遍历的一种方式，访问顺序遵循"根-左-右"的原则：
1. 首先访问根节点
2. 然后递归访问左子树
3. 最后递归访问右子树

前序遍历的特点是：**根节点总是第一个被访问**。

## 过程拆解

前序遍历的执行过程可以分解为以下步骤：

1. 检查当前节点是否为空（递归出口）
2. 如果非空，访问当前节点（输出节点值）
3. 递归调用前序遍历左子树
4. 递归调用前序遍历右子树

递归调用时，系统会自动维护一个调用栈，记录每次递归的返回位置。

## 文字版图示与状态变化表

以如下二叉树为例：

```
    A
   / \
  B   C
 /
D
```

### 状态变化表

| 步骤 | 当前节点 | 操作 | 访问序列 | 递归栈状态 |
|------|----------|------|----------|------------|
| 1 | A | 访问A | [A] | [A] |
| 2 | A.left → B | 进入左子树 | [A] | [A, B] |
| 3 | B | 访问B | [A, B] | [A, B] |
| 4 | B.left → D | 进入左子树 | [A, B] | [A, B, D] |
| 5 | D | 访问D | [A, B, D] | [A, B, D] |
| 6 | D.left → None | 左子树为空，返回 | [A, B, D] | [A, B, D] |
| 7 | D.right → None | 右子树为空，返回 | [A, B, D] | [A, B] |
| 8 | B.right → None | 右子树为空，返回 | [A, B, D] | [A] |
| 9 | A.right → C | 进入右子树 | [A, B, D] | [A, C] |
| 10 | C | 访问C | [A, B, D, C] | [A, C] |
| 11 | C.left → None | 左子树为空，返回 | [A, B, D, C] | [A, C] |
| 12 | C.right → None | 右子树为空，返回 | [A, B, D, C] | [A] |
| 13 | 返回 | 遍历结束 | [A, B, D, C] | [] |

## 小规模具体例子

### 遍历序列

对于上述二叉树，前序遍历的完整访问序列为：**A → B → D → C**

### 逐条解释

1. **A**：从根节点开始，首先访问根节点 A
2. **B**：根节点访问完毕后，递归进入左子树，访问左子树根节点 B
3. **D**：B 访问完毕后，递归进入其左子树，访问 D
4. **C**：D 的左右子树都为空，返回 B；B 的右子树为空，返回 A；最后递归进入 A 的右子树，访问 C

### 可视化路径

```
访问顺序：
A (根) ──→ B (A的左) ──→ D (B的左) ──→ 返回B ──→ 返回A ──→ C (A的右)
```

## 易错提醒

### 常见错误一：混淆遍历顺序

**错误代码：**
```python
def preorder(node):
    if not node:
        return
    preorder(node.left)  # 先递归左子树
    print(node.val)      # 再访问根节点 ← 这会变成中序遍历！
    preorder(node.right)
```

**正确做法：** 必须在递归左子树**之前**访问根节点。

### 常见错误二：忘记处理空节点

**错误代码：**
```python
def preorder(node):
    print(node.val)      # 没有检查 node 是否为空
    preorder(node.left)
    preorder(node.right)
```

**后果：** 当访问到叶子节点的子节点（None）时，`node.val` 会抛出 AttributeError，导致程序崩溃。

**正确做法：** 函数开头必须检查 `if not node: return`。

### 常见错误三：递归栈溢出

**问题场景：** 对于深度超过 Python 默认递归限制（约 1000 层）的树，会抛出 RecursionError。

**解决方案：** 使用非递归实现（显式栈）。

## 小练习

### 练习题目

请手动写出以下二叉树的前序遍历序列：

```
    1
   / \
  2   3
   \
    4
```

### 答案检查方式

1. **第一步**：确认根节点是第一个被访问的 → 序列第一个元素应为 `1`
2. **第二步**：访问根节点后，应进入左子树 → 接下来访问 `2`
3. **第三步**：访问 `2` 后，应进入其左子树（为空），再进入右子树 → 访问 `4`
4. **第四步**：`4` 的左右子树都为空，返回 `2`，再返回 `1`，最后进入右子树 → 访问 `3`

### 正确答案

前序遍历序列：**1 → 2 → 4 → 3**

### 验证方法

你可以通过以下代码验证你的答案：

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

root = TreeNode(1)
root.left = TreeNode(2)
root.right = TreeNode(3)
root.left.right = TreeNode(4)

def preorder(node):
    if not node:
        return []
    return [node.val] + preorder(node.left) + preorder(node.right)

print(preorder(root))  # 输出: [1, 2, 4, 3]
```
