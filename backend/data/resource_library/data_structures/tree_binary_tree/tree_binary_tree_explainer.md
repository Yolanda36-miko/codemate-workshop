## 核心概念

### 树的定义

树是由 n（n ≥ 0）个节点组成的有限集合：
- 当 n = 0 时称为空树
- 非空树有且只有一个根节点
- 其余节点可分为 m 个互不相交的子集，每个子集本身又是一棵树（子树）

### 基本术语速查

| 术语 | 定义 | 示例（以家族树类比） |
|------|------|---------------------|
| **根节点** | 没有父节点的节点 | 祖先 |
| **叶子节点** | 度为 0 的节点（无子节点） | 没有孩子的成员 |
| **内部节点** | 度大于 0 的节点 | 有孩子的成员 |
| **节点的度** | 节点拥有的子树个数 | 孩子数量 |
| **树的度** | 树中所有节点的度的最大值 | 最多孩子的成员 |
| **深度** | 从根到该节点的路径长度 | 第几代 |
| **高度** | 从该节点到最远叶子的路径长度 | — |
| **层序** | 从上到下、从左到右的编号 | — |
| **路径** | 从一个节点到另一个节点的节点序列 | 血缘线 |

### 二叉树定义

二叉树是每个节点最多有两个子树的树结构，子树有左右之分，次序不能颠倒。

**关键区分**：二叉树不是度为 2 的树——二叉树允许度为 0、1 或 2。

### 二叉树的分类

#### 1. 满二叉树
所有分支节点都有左子树和右子树，且所有叶子节点都在同一层。

```
        A               ← 第 1 层：2^0 = 1 个节点
      /   \
     B     C            ← 第 2 层：2^1 = 2 个节点
    / \   / \
   D   E F   G          ← 第 3 层：2^2 = 4 个节点
```

#### 2. 完全二叉树
除最后一层外，其余层节点数均达到最大；最后一层节点从左到右连续排列。

```
        A               ← 完全二叉树
      /   \
     B     C
    / \   /
   D   E F

   vs.

        A               ← 非完全二叉树
      /   \             （C 缺少左子但存在右子，
     B     C            不满足"从左到右连续"）
    / \     \
   D   E     F
```

#### 3. 二叉搜索树（BST）
- 左子树所有节点的值 < 根节点的值
- 右子树所有节点的值 > 根节点的值
- 左右子树本身也是 BST

```
        8
      /   \
     3     10
    / \      \
   1   6     14
      / \    /
     4   7  13
```

### 二叉树的关键性质

| 性质 | 公式 | 说明 |
|------|------|------|
| 第 i 层最大节点数 | 2^(i-1) | i ≥ 1 |
| 深度为 k 的最大节点数 | 2^k - 1 | 满二叉树 |
| n0 = n2 + 1 | — | 叶子数 = 度为2的节点数 + 1 |
| n 个节点的完全二叉树深度 | ⌊log₂n⌋ + 1 | — |
| 数组存储中，节点 i 的左右子 | 2i+1, 2i+2 | 0-indexed |

## 存储方式对比

### 链式存储

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right
```

**优点**：灵活，适合任意形态的二叉树。
**缺点**：每个节点有额外的指针开销。

### 数组存储

仅适用于完全二叉树（否则空间浪费严重）。按层序编号存入数组。

```python
# 满二叉树 [A,B,C,D,E,F,G] 的数组表示
tree = ['A', 'B', 'C', 'D', 'E', 'F', 'G']
# i=0(A): left=1(B), right=2(C)
# i=1(B): left=3(D), right=4(E)
```

## 常见错误

1. 混淆树的度与节点的度
2. 将普通二叉树与二叉搜索树的性质混淆
3. 对非完全二叉树使用数组存储导致索引错误
4. 混淆深度（自上而下）与高度（自下而上）的定义
