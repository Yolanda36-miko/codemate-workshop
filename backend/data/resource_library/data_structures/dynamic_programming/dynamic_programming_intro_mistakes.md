# 动态规划入门易错点总结

## 常见错误

### 错误一：状态定义不清晰

dp[i] 的含义模糊，导致后续转移方程错误。

### 错误二：初始条件设置错误

dp[0] 应该取 0 还是 1？不同问题定义不同，混淆会导致整体结果错误。

### 错误三：循环边界错误

循环从 i=2 开始还是 i=1 开始？数组索引越界或漏算。

### 错误四：空间优化时的更新顺序错误

使用滚动变量时，变量更新顺序导致状态被覆盖。

### 错误五：试图用贪心替代 DP

误以为每次选局部最优就能得到全局最优。

### 错误六：忘记处理无解或边界情况

输入 n=0 时未做处理。

## 错误原因

### 错误一原因

对动态规划的核心思想理解不足，没有认识到状态定义是 DP 的第一步和最关键的一步。

### 错误二原因

对初始条件的含义理解不清，不知道 dp[0] 表示什么，导致赋值错误。

### 错误三原因

对状态转移方程的依赖关系理解不清，不知道 dp[i] 依赖哪些子问题的解。

### 错误四原因

对滚动变量的更新顺序理解不清，不知道哪个值需要先保存，哪个可以直接覆盖。

### 错误五原因

对贪心算法和动态规划的适用场景理解不清，混淆了"最优解"和"方案数"等不同问题类型。

### 错误六原因

对输入边界情况考虑不周全，没有处理 n=0、n=1 等特殊情况。

## 正确理解

### 状态定义

状态定义是 DP 的核心，必须明确写出：

```
dp[i] = 到达第 i 阶楼梯的方法数
```

### 初始条件

dp[0] = 1 表示"从地面到第 0 阶有 1 种方式（原地不动）"，这是状态转移方程成立的基础。

### 循环边界

dp[i] = dp[i-1] + dp[i-2]，所以 i 必须从 2 开始。

### 空间优化

滚动变量的更新顺序：先计算 curr，再更新 prev2，最后更新 prev1。

### 贪心 vs DP

- **贪心**：每次选择局部最优，适用于求最优解（如最短路径）
- **DP**：考虑所有可能，适用于求方案数或最优解

### 边界情况

必须处理 n=0、n=1 等特殊情况，避免数组越界。

## 错误例子

### 错误一：状态定义不清晰

**错误代码**：

```cpp
int climbStairs(int n) {
    vector<int> dp(n+1);
    // dp[i] 到底表示什么？没有明确说明
    dp[0] = 1;
    dp[1] = 1;
    for (int i = 2; i <= n; i++) {
        dp[i] = dp[i-1] + dp[i-2];  // 转移方程可能错误
    }
    return dp[n];
}
```

**错误后果**：如果状态定义错误，转移方程也会错误，导致输出错误结果。

### 错误二：初始条件设置错误

**错误代码**：

```cpp
int climbStairs(int n) {
    vector<int> dp(n+1);
    dp[0] = 0;  // 错误：应该是 1
    dp[1] = 1;
    for (int i = 2; i <= n; i++) {
        dp[i] = dp[i-1] + dp[i-2];
    }
    return dp[n];
}
```

**错误后果**：

| n | 正确结果 | 错误结果 |
|---|---------|---------|
| 1 | 1 | 1 |
| 2 | 2 | 1 |
| 3 | 3 | 2 |
| 4 | 5 | 3 |

### 错误三：循环边界错误

**错误代码**：

```cpp
int climbStairs(int n) {
    vector<int> dp(n+1);
    dp[0] = 1;
    dp[1] = 1;
    for (int i = 1; i <= n; i++) {  // 错误：应该从 2 开始
        dp[i] = dp[i-1] + dp[i-2];
    }
    return dp[n];
}
```

**错误后果**：当 i=1 时，dp[i-2] = dp[-1]，数组越界。

### 错误四：空间优化时的更新顺序错误

**错误代码**：

```cpp
int climbStairs(int n) {
    if (n <= 1) return 1;
    int prev2 = 1, prev1 = 1, curr;
    for (int i = 2; i <= n; i++) {
        curr = prev1 + prev2;
        prev1 = curr;  // 错误：先更新 prev1
        prev2 = prev1;  // prev2 被覆盖为新的 prev1
    }
    return curr;
}
```

**错误后果**：prev2 被错误地更新为新的 prev1，导致后续计算错误。

### 错误五：试图用贪心替代 DP

**错误理解**："爬楼梯问题，每次走 2 阶最快，所以最优解是 n/2 步"。

**错误后果**：爬楼梯问题问的是"方法数"，不是"最少步数"，贪心完全不适用。

### 错误六：忘记处理边界情况

**错误代码**：

```cpp
int climbStairs(int n) {
    vector<int> dp(n+1);  // 当 n=0 时，dp[1] 越界
    dp[0] = 1;
    dp[1] = 1;
    for (int i = 2; i <= n; i++) {
        dp[i] = dp[i-1] + dp[i-2];
    }
    return dp[n];
}
```

**错误后果**：当 n=0 时，访问 dp[1] 会导致数组越界。

## 正确做法

### 错误一正确做法

```cpp
int climbStairs(int n) {
    vector<int> dp(n+1);
    // 明确状态定义：dp[i] = 到达第 i 阶的方法数
    dp[0] = 1;
    dp[1] = 1;
    for (int i = 2; i <= n; i++) {
        dp[i] = dp[i-1] + dp[i-2];
    }
    return dp[n];
}
```

### 错误二正确做法

```cpp
int climbStairs(int n) {
    vector<int> dp(n+1);
    dp[0] = 1;  // 正确：原地不动有一种方法
    dp[1] = 1;
    for (int i = 2; i <= n; i++) {
        dp[i] = dp[i-1] + dp[i-2];
    }
    return dp[n];
}
```

### 错误三正确做法

```cpp
int climbStairs(int n) {
    vector<int> dp(n+1);
    dp[0] = 1;
    dp[1] = 1;
    for (int i = 2; i <= n; i++) {  // 正确：从 2 开始
        dp[i] = dp[i-1] + dp[i-2];
    }
    return dp[n];
}
```

### 错误四正确做法

```cpp
int climbStairs(int n) {
    if (n <= 1) return 1;
    int prev2 = 1, prev1 = 1, curr;
    for (int i = 2; i <= n; i++) {
        curr = prev1 + prev2;
        prev2 = prev1;  // 先更新 prev2
        prev1 = curr;   // 再更新 prev1
    }
    return curr;
}
```

### 错误五正确做法

理解问题类型：爬楼梯问题是求"方案数"，不是"最优解"，必须使用 DP。

### 错误六正确做法

```cpp
int climbStairs(int n) {
    if (n <= 1) return 1;  // 处理边界情况
    vector<int> dp(n+1);
    dp[0] = 1;
    dp[1] = 1;
    for (int i = 2; i <= n; i++) {
        dp[i] = dp[i-1] + dp[i-2];
    }
    return dp[n];
}
```

### 错误与正确对比

| 错误类型 | 错误代码 | 正确代码 |
|----------|----------|----------|
| 状态定义 | 未明确说明 | 明确写出 dp[i] 的含义 |
| 初始条件 | dp[0] = 0 | dp[0] = 1 |
| 循环边界 | i = 1 | i = 2 |
| 更新顺序 | prev1 = curr; prev2 = prev1 | prev2 = prev1; prev1 = curr |
| 贪心替代 | 用贪心求方案数 | 使用 DP |
| 边界处理 | 未处理 n=0 | if (n <= 1) return 1 |

## 自查题

### 题目一

**题目描述**：指出以下代码的错误并修正。

```cpp
int climbStairs(int n) {
    vector<int> dp(n);  // 错误1
    dp[0] = 0;  // 错误2
    for (int i = 1; i <= n; i++) {  // 错误3
        dp[i] = dp[i-1] + dp[i-2];
    }
    return dp[n];
}
```

**答案要点**：

1. **数组大小错误**：`vector<int> dp(n)` 应该是 `vector<int> dp(n+1)`

2. **初始条件错误**：`dp[0] = 0` 应该是 `dp[0] = 1`

3. **循环边界错误**：`i = 1` 应该是 `i = 2`，且缺少 `dp[1] = 1` 的初始化

**修正代码**：

```cpp
int climbStairs(int n) {
    if (n <= 1) return 1;
    vector<int> dp(n+1);
    dp[0] = 1;
    dp[1] = 1;
    for (int i = 2; i <= n; i++) {
        dp[i] = dp[i-1] + dp[i-2];
    }
    return dp[n];
}
```

### 题目二

**题目描述**：指出以下空间优化版本的错误并修正。

```cpp
int climbStairs(int n) {
    if (n <= 1) return 1;
    int a = 1, b = 1, c;
    for (int i = 2; i <= n; i++) {
        c = a + b;
        a = c;
        b = a;
    }
    return c;
}
```

**答案要点**：

**错误**：变量更新顺序错误。`a = c` 后，`b = a` 实际上变成了 `b = c`，丢失了原来的 `a` 值。

**修正代码**：

```cpp
int climbStairs(int n) {
    if (n <= 1) return 1;
    int a = 1, b = 1, c;
    for (int i = 2; i <= n; i++) {
        c = a + b;
        a = b;  // 先保存旧的 b
        b = c;  // 再更新 b
    }
    return c;
}
```

### 题目三

**题目描述**：每次可走 1 阶或 3 阶，写出正确的状态定义、转移方程和初始条件。

**答案要点**：

**状态定义**：

```
dp[i] = 到达第 i 阶的方法数
```

**状态转移方程**：

```
dp[i] = dp[i-1] + dp[i-3]  (i >= 3)
```

**初始条件**：

```
dp[0] = 1  // 原地不动
dp[1] = 1  // 只能走 1 阶
dp[2] = 1  // 只能走 1+1 阶
```

**验证**：

```
dp[3] = dp[2] + dp[0] = 1 + 1 = 2  (1+1+1, 3)
dp[4] = dp[3] + dp[1] = 2 + 1 = 3  (1+1+1+1, 1+3, 3+1)
dp[5] = dp[4] + dp[2] = 3 + 1 = 4
```
