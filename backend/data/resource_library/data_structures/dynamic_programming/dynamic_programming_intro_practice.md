## 综合题

### 综合题一

**题目描述**

一个楼梯有 n 阶，每次可以走 1 阶或 2 阶，但要求不能连续走 2 阶（即不能连续跳两级）。请定义状态（可能需要二维状态），写出状态转移方程和初始条件，并计算 n=5 时的结果。

### 综合题二

**题目描述**

给定一个整数数组 cost，其中 cost[i] 表示爬过第 i 阶需要支付的体力值。每次可以从第 i 阶爬到第 i+1 或 i+2 阶，求到达第 n 阶的最小体力消耗。

**示例输入**：cost = [10, 15, 20]，n = 2（到达第 2 阶）

**示例输出**：15（选择 0 → 2，消耗 15）

## 可选答案要点

### 基础题一答案

**所有上楼方式**：

1. 1 + 1 + 1 + 1
2. 1 + 1 + 2
3. 1 + 2 + 1
4. 2 + 1 + 1
5. 2 + 2

共 5 种方式，验证 dp[4] = 5 正确。

### 基础题二答案

**递推公式**：

```
dp[i] = dp[i-1] + dp[i-2]
```

**初始条件**：

```
dp[0] = 1
dp[1] = 1
```

**计算 dp[6]**：

```
dp[2] = dp[1] + dp[0] = 1 + 1 = 2
dp[3] = dp[2] + dp[1] = 2 + 1 = 3
dp[4] = dp[3] + dp[2] = 3 + 2 = 5
dp[5] = dp[4] + dp[3] = 5 + 3 = 8
dp[6] = dp[5] + dp[4] = 8 + 5 = 13
```

**结果**：dp[6] = 13

### 进阶题一答案

```cpp
int climbStairs(int n) {
    if (n <= 1) return 1;
    vector<int> dp(n+1);
    dp[0] = 1;
    dp[1] = 1;
    for (int i = 2; i <= n; i++) {
        dp[i] = dp[i-1] + dp[i-2];
    }
    return dp[n];
}
```

### 进阶题二答案

**状态定义**：

```
dp[i] = 到达第 i 阶的方法数
```

**状态转移方程**：

```
dp[i] = dp[i-1] + dp[i-2] + dp[i-3]  (i >= 3)
```

**初始条件**：

```
dp[0] = 1
dp[1] = 1
dp[2] = 2
```

**计算 dp[5]**：

```
dp[3] = dp[2] + dp[1] + dp[0] = 2 + 1 + 1 = 4
dp[4] = dp[3] + dp[2] + dp[1] = 4 + 2 + 1 = 7
dp[5] = dp[4] + dp[3] + dp[2] = 7 + 4 + 2 = 13
```

**结果**：dp[5] = 13

### 进阶题三答案

**执行效率对比**：

| 方法 | n=40 的执行时间 | 原因 |
|------|---------------|------|
| 递归（无记忆化） | 几乎无法完成 | O(2^40) ≈ 10^12 次调用 |
| 递归+记忆化 | 瞬间完成 | O(40) = 40 次计算 |
| 迭代 DP | 瞬间完成 | O(40) = 40 次计算 |

**原因分析**：递归无记忆化存在大量重复计算，而记忆化和迭代 DP 每个子问题只计算一次。

### 综合题一答案

**状态定义**：

```
dp[i][0] = 到达第 i 阶，最后一步走 1 阶的方法数
dp[i][1] = 到达第 i 阶，最后一步走 2 阶的方法数
```

**状态转移方程**：

```
dp[i][0] = dp[i-1][0] + dp[i-1][1]  (从 i-1 阶走 1 阶上来，前一步可以是任意)
dp[i][1] = dp[i-2][0]  (从 i-2 阶走 2 阶上来，前一步不能是 2 阶)
```

**初始条件**：

```
dp[0][0] = 1, dp[0][1] = 0
dp[1][0] = 1, dp[1][1] = 0
```

**计算 n=5**：

```
dp[2][0] = dp[1][0] + dp[1][1] = 1 + 0 = 1
dp[2][1] = dp[0][0] = 1
总方法数 = 1 + 1 = 2

dp[3][0] = dp[2][0] + dp[2][1] = 1 + 1 = 2
dp[3][1] = dp[1][0] = 1
总方法数 = 2 + 1 = 3

dp[4][0] = dp[3][0] + dp[3][1] = 2 + 1 = 3
dp[4][1] = dp[2][0] = 1
总方法数 = 3 + 1 = 4

dp[5][0] = dp[4][0] + dp[4][1] = 3 + 1 = 4
dp[5][1] = dp[3][0] = 2
总方法数 = 4 + 2 = 6
```

**结果**：n=5 时共有 6 种方法

### 综合题二答案

**状态定义**：

```
dp[i] = 到达第 i 阶的最小体力消耗
```

**状态转移方程**：

```
dp[i] = min(dp[i-1], dp[i-2]) + cost[i]
```

**初始条件**：

```
dp[0] = cost[0]
dp[1] = cost[1]
```

**示例计算**（cost = [10, 15, 20]）：

```
dp[0] = 10
dp[1] = 15
dp[2] = min(dp[1], dp[0]) + cost[2] = min(15, 10) + 20 = 30
```

**到达第 2 阶的最小消耗**：min(dp[1], dp[2]) = min(15, 30) = 15

**优化版本**：可以只考虑到达顶楼（不需要经过最后一阶）：

```
dp[i] = min(dp[i-1] + cost[i-1], dp[i-2] + cost[i-2])
dp[0] = 0, dp[1] = 0
dp[2] = min(10, 15) = 10
```
