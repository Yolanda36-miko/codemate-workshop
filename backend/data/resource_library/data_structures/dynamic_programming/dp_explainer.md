# 动态规划入门讲解

## 适合对象
初学动态规划的学生，需建立状态定义和转移方程的思维。

## 核心概念

### 动态规划的两个关键性质
1. **最优子结构**：大问题的最优解包含子问题的最优解。
2. **重叠子问题**：不同路径会重复计算相同的子问题。

### 状态定义与转移方程
- **状态定义**：用 dp[i] 或 dp[i][j] 描述子问题的解。
- **转移方程**：dp[i] = f(dp[i-1], ..., 输入[i])，是 DP 的核心。
- 从简单例子入手：斐波那契 → 爬楼梯 → 最小路径和 → 背包问题。

### 两种实现方式
- **自顶向下（记忆化搜索）**：递归 + 缓存已解结果。
- **自底向上（递推填表）**：从最小子问题开始迭代计算。
- 自顶向下易于构思，自底向上通常更高效。

### 经典 DP 问题
1. 0-1 背包：dp[i][w] = max(dp[i-1][w], dp[i-1][w-wt[i]] + val[i])
2. 最长公共子序列（LCS）
3. 最长递增子序列（LIS）

### 易错点
1. 状态定义不完整，遗漏维度。
2. 转移方程遗漏边界情况。
3. 自顶向下和自底向上选择不当导致实现复杂。
