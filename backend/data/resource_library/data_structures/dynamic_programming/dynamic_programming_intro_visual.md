# 动态规划入门图解讲解

## 核心概念

### 动态规划的核心思想

动态规划（Dynamic Programming, DP）是一种将**大问题分解为重叠子问题**的算法思想。通过**记录子问题的解**（记忆化），避免重复计算，从而用空间换时间。

### 爬楼梯问题

**问题描述**：假设你正在爬楼梯，需要 n 阶才能到达楼顶。每次你可以爬 1 或 2 个台阶，问有多少种不同的方法可以爬到楼顶？

### 状态定义

**dp[i]**：表示到达第 i 阶楼梯的方法数。

### 状态转移方程

```
dp[i] = dp[i-1] + dp[i-2]
```

**解释**：到达第 i 阶有两种方式：
1. 从第 i-1 阶爬 1 阶上来
2. 从第 i-2 阶爬 2 阶上来

### 初始条件

```
dp[0] = 1  // 站在地面，有一种方法（原地不动）
dp[1] = 1  // 到第 1 阶只有一种方法（直接爬 1 阶）
```

### 与递归的对比

**递归（暴力搜索）**：

```
fib(5) = fib(4) + fib(3)
fib(4) = fib(3) + fib(2)  ← fib(3) 重复计算
fib(3) = fib(2) + fib(1)  ← fib(2) 重复计算
...
```

**动态规划**：通过填表，每个子问题只计算一次。

## 过程拆解

### 步骤一：定义问题规模

确定楼梯阶数 n，目标是计算 dp[n]。

### 步骤二：初始化 dp 数组

```
dp[0] = 1
dp[1] = 1
```

### 步骤三：填充 dp 数组

从 i = 2 到 n，依次计算：

```
dp[i] = dp[i-1] + dp[i-2]
```

### 步骤四：返回结果

返回 dp[n]，即为到达第 n 阶的方法数。

### 核心特性

| 特性 | 说明 |
|------|------|
| 重叠子问题 | dp[i] 依赖 dp[i-1] 和 dp[i-2]，这些子问题会被重复使用 |
| 最优子结构 | 大问题的解可以由子问题的解构成 |

## 文字版图示与状态变化表

### n = 5 的爬楼梯问题

#### dp 数组填充过程

| i | dp[i-2] | dp[i-1] | dp[i] = dp[i-1] + dp[i-2] | dp 数组状态 |
|---|---------|---------|--------------------------|-------------|
| 0 | - | - | 1（初始条件） | [1] |
| 1 | - | - | 1（初始条件） | [1, 1] |
| 2 | dp[0]=1 | dp[1]=1 | 1 + 1 = 2 | [1, 1, 2] |
| 3 | dp[1]=1 | dp[2]=2 | 1 + 2 = 3 | [1, 1, 2, 3] |
| 4 | dp[2]=2 | dp[3]=3 | 2 + 3 = 5 | [1, 1, 2, 3, 5] |
| 5 | dp[3]=3 | dp[4]=5 | 3 + 5 = 8 | [1, 1, 2, 3, 5, 8] |

#### 递归调用树（对比）

```
          fib(5)
         /     \
    fib(4)     fib(3) ← 重复
    /   \       /   \
 fib(3) fib(2) fib(2) fib(1)
 /  \    / \    / \
fib(2) fib(1) fib(1) fib(0)
/ \
fib(1) fib(0)
```

**重复计算统计**：

| 函数调用 | 调用次数 |
|----------|----------|
| fib(5) | 1 |
| fib(4) | 1 |
| fib(3) | 2 |
| fib(2) | 3 |
| fib(1) | 5 |
| fib(0) | 3 |

**结论**：递归调用有大量重复计算（fib(2) 计算了 3 次），动态规划通过填表避免了这些重复。

## 小规模具体例子

### n = 1

```
dp[1] = 1

方法：[1]
```

### n = 2

```
dp[2] = dp[1] + dp[0] = 1 + 1 = 2

方法：[1+1, 2]
```

### n = 3

```
dp[3] = dp[2] + dp[1] = 2 + 1 = 3

方法：[1+1+1, 1+2, 2+1]
```

### n = 4

```
dp[4] = dp[3] + dp[2] = 3 + 2 = 5

方法：[1+1+1+1, 1+1+2, 1+2+1, 2+1+1, 2+2]
```

### n = 5

```
dp[5] = dp[4] + dp[3] = 5 + 3 = 8

方法：[1+1+1+1+1, 1+1+1+2, 1+1+2+1, 1+2+1+1, 2+1+1+1, 1+2+2, 2+1+2, 2+2+1]
```

### 递推关系表

| n | dp[n] | 方法数 |
|---|-------|--------|
| 0 | 1 | 1（原地不动） |
| 1 | 1 | 1 |
| 2 | 2 | 2 |
| 3 | 3 | 3 |
| 4 | 5 | 5 |
| 5 | 8 | 8 |

**观察**：这其实是斐波那契数列！dp[n] = Fib(n+1)

## 易错提醒

### 错误一：状态定义不清

**错误**：不知道 dp[i] 表示什么。

**正确做法**：明确写出状态定义，例如"dp[i] 表示到达第 i 阶楼梯的方法数"。

### 错误二：初始条件错误

**错误**：dp[0] = 0（认为到第 0 阶没有方法）。

**正确做法**：dp[0] = 1，表示从地面到第 0 阶有 1 种方式（原地不动）。这是状态转移方程成立的基础。

### 错误三：转移方程适用范围

**错误**：从 i = 1 开始计算 dp[i]。

**正确做法**：dp[i] 依赖 dp[i-1] 和 dp[i-2]，所以 i 必须从 2 开始。

### 错误四：动态规划的误区

**错误理解**：动态规划就是"用数组存结果"。

**正确理解**：用数组存结果只是实现方式，核心是**状态定义**和**状态转移方程**。

### 错误五：与贪心的混淆

**错误**：认为每次选择最优的一步就能得到全局最优。

**正确理解**：贪心只做局部最优选择，不一定得到全局最优；动态规划考虑所有可能的选择。

## 小练习

### 练习题目

"每次可以走 1 阶、2 阶或 3 阶，问到达第 n 阶有多少种方法？"

### 问题拆解

1. **定义状态**：dp[i] 表示到达第 i 阶的方法数
2. **写出状态转移方程**：到达第 i 阶可以从 i-1、i-2 或 i-3 阶上来
3. **给出初始条件**：dp[0], dp[1], dp[2]
4. **计算 n=4 时的结果**

### 答案要点

**状态定义**：

```
dp[i] = 到达第 i 阶的方法数
```

**状态转移方程**：

```
dp[i] = dp[i-1] + dp[i-2] + dp[i-3]
```

**初始条件**：

```
dp[0] = 1  // 原地不动
dp[1] = 1  // 只有 1 种方法：走 1 阶
dp[2] = 2  // 两种方法：1+1, 2
```

**n=4 的计算过程**：

```
dp[3] = dp[2] + dp[1] + dp[0] = 2 + 1 + 1 = 4
dp[4] = dp[3] + dp[2] + dp[1] = 4 + 2 + 1 = 7
```

**n=4 的结果**：7 种方法

### 验证方法

你可以通过枚举验证：

```
1+1+1+1
1+1+2
1+2+1
2+1+1
2+2
1+3
3+1
```

共 7 种方法，验证通过。
