# 数据结构综合项目实践

## 适合对象
已完成核心模块学习，需要通过综合项目巩固数据结构与算法的学生。

## 项目建议

### 入门级项目
- **表达式计算器**：综合使用栈实现中缀表达式求值。
- **迷宫求解器**：使用 BFS（最短路径）或 DFS（所有路径）求解迷宫。
- **简单文本编辑器**：使用链表管理文本缓冲区。

### 进阶级项目
- **文件目录树遍历**：用树的遍历实现目录扫描和结构输出。
- **简单搜索引擎**：综合散列表（倒排索引）+ 排序（结果排序）。
- **路径规划器**：使用 Dijkstra/A* 算法实现地图路径规划。

### 实践要点
1. **数据结构选型**：分析问题的增删查改需求，选择合适的数据结构。
2. **复杂度优化**：从暴力解法出发，逐步优化时间/空间复杂度。
3. **测试与调试**：构造边界测试用例，验证数据结构的正确性。

### 学习建议
从小型项目开始（表达式计算器、迷宫求解），逐步挑战复杂项目（搜索引擎、路径规划器）。每个项目关注原理后再动手实现。
