## 可选答案要点

### 基础题一答案

**Partition 过程**（pivot = 2）：

| 步骤 | j | arr[j] | arr[j] <= pivot? | i | 数组状态 |
|------|---|--------|------------------|---|----------|
| 初始 | - | - | - | -1 | [8, 3, 5, 4, 7, 6, **2**] |
| 1 | 0 | 8 | 否 | -1 | [8, 3, 5, 4, 7, 6, 2] |
| 2 | 1 | 3 | 否 | -1 | [8, 3, 5, 4, 7, 6, 2] |
| 3 | 2 | 5 | 否 | -1 | [8, 3, 5, 4, 7, 6, 2] |
| 4 | 3 | 4 | 否 | -1 | [8, 3, 5, 4, 7, 6, 2] |
| 5 | 4 | 7 | 否 | -1 | [8, 3, 5, 4, 7, 6, 2] |
| 6 | 5 | 6 | 否 | -1 | [8, 3, 5, 4, 7, 6, 2] |
| 7 | - | - | - | -1 | 交换 arr[i+1]=arr[0]=8 和 pivot=2 |

**最终结果**：`[2, 3, 5, 4, 7, 6, 8]`

**观察**：这是最坏情况的 partition，pivot 是最小元素，分区后只减少了一个元素。

### 基础题二答案

**错误**。

**理由**：

1. 时间复杂度是渐近分析，只反映数据规模很大时的增长趋势。
2. 插入排序在数据量小或基本有序时，实际运行时间可能更快。
3. 快速排序有递归调用的开销，插入排序是原地排序且常数因子小。

### 进阶题一答案

```cpp
void quickSort(int arr[], int low, int high) {
    if (low >= high) return;  // 空缺1
    int pivotPos = partition(arr, low, high);
    quickSort(arr, low, pivotPos - 1);  // 空缺2
    quickSort(arr, pivotPos + 1, high);  // 空缺3
}

int partition(int arr[], int low, int high) {
    int pivot = arr[high];
    int i = low - 1;  // 空缺4

    for (int j = low; j < high; j++) {  // 空缺5
        if (arr[j] <= pivot) {
            i++;
            swap(arr[i], arr[j]);
        }
    }
    swap(arr[i + 1], arr[high]);
    return i + 1;  // 空缺6
}
```

### 进阶题二答案

**a) 时间复杂度：O(n²)**

**原因**：每次选择的 pivot 是最小元素，分区后左半部分为空，右半部分为 n-1 个元素，递归深度为 n。

**b) 时间复杂度：O(n²)**

**原因**：每次选择的 pivot 是最小元素（降序排列时最后一个元素最小），分区后左半部分为空，右半部分为 n-1 个元素，递归深度为 n。

**c) 时间复杂度：O(n log n)**

**原因**：随机数组下，中间元素作为 pivot 能将数组大致均匀划分，递归深度为 log n。

### 进阶题三答案

**快速排序**：不稳定

**示例**：`[2a, 1, 2b]`

排序过程：
- pivot = 2b
- partition 后：`[1, 2a, 2b]` 或 `[1, 2b, 2a]`
- 如果是后者，2a 和 2b 的相对顺序改变

**归并排序**：稳定

**示例**：`[2a, 1, 2b]`

排序过程：
- 分割：`[2a]` 和 `[1, 2b]`
- 合并：`[1, 2a, 2b]`（相等元素保持原始顺序）

### 综合题一答案

**选择归并排序**，因为它是稳定的。

**数据结构设计**：

```cpp
struct Student {
    int score;
    int id;
};
```

**排序策略**：

```cpp
bool compare(const Student& a, const Student& b) {
    if (a.score != b.score) {
        return a.score < b.score;
    }
    return a.id < b.id;  // 成绩相同时按学号升序
}
```

### 综合题二答案

**三指针分区算法**：

```cpp
void sortColors(vector<int>& nums) {
    int lt = 0, i = 0, gt = nums.size() - 1;

    while (i <= gt) {
        if (nums[i] == 0) {
            swap(nums[lt], nums[i]);
            lt++;
            i++;
        } else if (nums[i] == 1) {
            i++;
        } else {  // nums[i] == 2
            swap(nums[i], nums[gt]);
            gt--;
        }
    }
}
```

**时间复杂度**：O(n)，每个元素最多被访问一次。

**空间复杂度**：O(1)，原地排序。
