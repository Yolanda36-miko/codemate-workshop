# 快速排序与稳定性图解讲解

## 核心概念

### 快速排序的核心思想

快速排序采用**分治（Divide and Conquer）**策略：
1. **选取基准元素（pivot）**：从数组中选择一个元素作为基准
2. **分区（Partition）**：将数组分为两部分，左边元素小于等于 pivot，右边元素大于 pivot
3. **递归排序**：对左右两部分分别递归调用快速排序
4. **合并**：无需合并，因为排序是就地进行的

**特点**：平均时间复杂度 O(n log n)，原地排序，空间复杂度 O(log n)（递归栈）。

### 稳定性定义

**稳定性**：排序后，相等元素的原始相对顺序保持不变。

**不稳定示例**：
- 原始数组：[3a, 3b]（3a 在 3b 之前）
- 排序后：[3b, 3a]（相对顺序改变）→ 不稳定

**稳定示例**：
- 原始数组：[3a, 3b]
- 排序后：[3a, 3b]（相对顺序不变）→ 稳定

**快速排序为什么通常不稳定**：在分区过程中，相等元素可能被交换到不同位置，导致相对顺序改变。

## 过程拆解

### Partition 过程（左右指针交换法）

以数组 [3a, 1, 2, 3b, 0] 为例，选取最后一个元素 0 作为 pivot：

1. **初始化**：设置左指针 i = 0，右指针 j = 3（pivot 位置）
2. **右指针移动**：j 从右向左扫描，找小于 pivot 的元素
3. **左指针移动**：i 从左向右扫描，找大于 pivot 的元素
4. **交换元素**：当 i < j 时，交换 arr[i] 和 arr[j]
5. **归位 pivot**：当 i == j 时，交换 arr[i] 和 pivot

### 递归调用顺序

```
quickSort(arr, low, high):
    if low >= high:
        return
    pivot_pos = partition(arr, low, high)
    quickSort(arr, low, pivot_pos - 1)   // 先排序左半部分
    quickSort(arr, pivot_pos + 1, high)  // 再排序右半部分
```

## 文字版图示与状态变化表

### 示例数组

```
[3a, 1, 2, 3b, 0]
  ↑           ↑
  i=0        j=4 (pivot)
```

**说明**：3a 和 3b 表示两个值相等但原始位置不同的元素，用于追踪相对顺序。

### Partition 过程（选取最后一个元素 0 作为 pivot）

| 步骤 | 数组状态 | i | j | 操作说明 |
|------|----------|---|---|----------|
| 初始 | [3a, 1, 2, 3b, **0**] | 0 | 4 | pivot = 0，j 指向 pivot 前一个位置（j=3） |
| 1 | [3a, 1, 2, **3b**, 0] | 0 | 3 | j=3，arr[j]=3b > 0，j-- |
| 2 | [3a, 1, **2**, 3b, 0] | 0 | 2 | j=2，arr[j]=2 > 0，j-- |
| 3 | [3a, **1**, 2, 3b, 0] | 0 | 1 | j=1，arr[j]=1 > 0，j-- |
| 4 | [**3a**, 1, 2, 3b, 0] | 0 | 0 | j=0，arr[j]=3a > 0，j--（j < i，退出循环） |
| 5 | [**0**, 1, 2, 3b, **3a**] | 0 | 0 | 交换 arr[i]=3a 和 pivot=0，pivot 归位 |

**Partition 完成后**：

```
[0, 1, 2, 3b, 3a]
       ↑
     pivot_pos=0
```

**观察**：3a 和 3b 的相对顺序已经改变（原始顺序 3a 在 3b 之前，现在 3b 在 3a 之前），这就是不稳定的表现。

### 递归排序过程

**第一次递归**：排序右半部分 [1, 2, 3b, 3a]

| 步骤 | 数组状态 | i | j | 操作说明 |
|------|----------|---|---|----------|
| 初始 | [1, 2, **3b**, **3a**] | 0 | 2 | pivot = 3a，j=2 |
| 1 | [1, **2**, 3b, 3a] | 0 | 2 | j=2，arr[j]=3b < 3a，停止 |
| 2 | [**1**, 2, 3b, 3a] | 0 | 2 | i=0，arr[i]=1 < 3a，i++ |
| 3 | [1, **2**, 3b, 3a] | 1 | 2 | i=1，arr[i]=2 < 3a，i++ |
| 4 | [1, 2, **3b**, 3a] | 2 | 2 | i=2，arr[i]=3b < 3a，i++（i > j，退出循环） |
| 5 | [1, 2, **3a**, **3b**] | 2 | 2 | 交换 arr[i]=3b 和 pivot=3a |

**第二次递归**：排序左半部分 [1, 2]

| 步骤 | 数组状态 | i | j | 操作说明 |
|------|----------|---|---|----------|
| 初始 | [**1**, **2**] | 0 | 0 | pivot = 2，j=0 |
| 1 | [**1**, 2] | 0 | 0 | j=0，arr[j]=1 < 2，停止 |
| 2 | [**1**, 2] | 0 | 0 | i=0，arr[i]=1 < 2，i++（i > j，退出循环） |
| 3 | [**1**, **2**] | 0 | 0 | 交换 arr[i]=1 和 pivot=2？不交换（已经有序） |

## 小规模具体例子

### 完整排序过程

**原始数组**：[3a, 1, 2, 3b, 0]

**第一次 Partition（pivot=0）**：

```
初始：[3a, 1, 2, 3b, 0]
结束：[0, 1, 2, 3b, 3a]
      ↑
    pivot_pos=0
```

**递归调用**：
- quickSort(arr, 1, 4) → 排序 [1, 2, 3b, 3a]

**第二次 Partition（pivot=3a）**：

```
初始：[1, 2, 3b, 3a]
结束：[1, 2, 3a, 3b]
          ↑
        pivot_pos=2
```

**递归调用**：
- quickSort(arr, 1, 1) → 单元素，返回
- quickSort(arr, 3, 3) → 单元素，返回

**最终结果**：[0, 1, 2, 3a, 3b]

### 稳定性分析

**情况一**：上述例子最终结果是 [0, 1, 2, 3a, 3b]，相对顺序保持不变。

**情况二**：如果选择不同的 pivot 或使用不同的分区方案，可能得到不同结果。

**关键观察**：在第一次 Partition 过程中，3a 和 3b 的顺序**确实被交换了**（从 [3a, ..., 3b] 变成了 [..., 3b, 3a]），只是在后续递归中又交换回来了。

**更明显的不稳定示例**：

**数组**：[2a, 2b, 1]

**Partition（pivot=1）**：

| 步骤 | 数组状态 | i | j | 说明 |
|------|----------|---|---|------|
| 初始 | [2a, 2b, **1**] | 0 | 1 | pivot=1 |
| 1 | [**2a**, 2b, 1] | 0 | 1 | j=1，arr[j]=2b > 1，j-- |
| 2 | [**2a**, 2b, 1] | 0 | 0 | j=0，arr[j]=2a > 1，j--（j < i） |
| 3 | [**1**, 2b, **2a**] | 0 | 0 | 交换 arr[i]=2a 和 pivot=1 |

**最终结果**：[1, 2b, 2a]

**结论**：2a 和 2b 的原始顺序是 2a 在 2b 之前，但排序后变成了 2b 在 2a 之前，证明快速排序是**不稳定**的。

## 易错提醒

### 错误一：基准元素选择不当

**问题**：如果每次选择最小或最大元素作为 pivot，快速排序会退化为 O(n²)。

**解决方案**：
- 随机选择 pivot
- 选择三数取中（首、尾、中间元素的中位数）

### 错误二：分区时指针相遇位置错误

**问题**：在左右指针交换法中，当 i >= j 时应停止，否则会越界或交换错误。

**解决方案**：在循环条件中严格检查 i < j。

### 错误三：递归边界条件遗漏

**问题**：忘记检查 low >= high，导致无限递归。

**正确做法**：

```cpp
void quickSort(int arr[], int low, int high) {
    if (low >= high) return;  // 必须检查
    int pivot_pos = partition(arr, low, high);
    quickSort(arr, low, pivot_pos - 1);
    quickSort(arr, pivot_pos + 1, high);
}
```

### 错误四：稳定性误区

**错误理解**："相等元素值一样，顺序无所谓"。

**正确理解**：稳定性有实际意义，例如：
- 二次排序：先按分数排序，再按姓名排序
- 对象排序：保持原始顺序的语义

## 小练习

### 练习题目

请模拟对数组 [5a, 3, 5b, 2, 4] 执行一次以最后一个元素为基准的 Partition 过程：

1. 写出每一步的数组状态、i 和 j 的值
2. 写出分区后的数组状态
3. 观察 5a 和 5b 的相对顺序是否改变

### 答案检查方式

**Partition 过程**：

| 步骤 | 数组状态 | i | j | 操作说明 |
|------|----------|---|---|----------|
| 初始 | [5a, 3, 5b, 2, **4**] | 0 | 3 | pivot = 4，j=3 |
| 1 | [5a, 3, 5b, **2**, 4] | 0 | 3 | j=3，arr[j]=2 < 4，停止 |
| 2 | [**5a**, 3, 5b, 2, 4] | 0 | 3 | i=0，arr[i]=5a > 4，停止 |
| 3 | [**2**, 3, 5b, **5a**, 4] | 1 | 2 | 交换 arr[i]=5a 和 arr[j]=2，i++，j-- |
| 4 | [2, **3**, 5b, 5a, 4] | 1 | 2 | i=1，arr[i]=3 < 4，i++ |
| 5 | [2, 3, **5b**, 5a, 4] | 2 | 2 | i=2，arr[i]=5b > 4，停止 |
| 6 | [2, 3, **4**, 5a, **5b**] | 2 | 2 | 交换 arr[i]=5b 和 pivot=4 |

**分区后数组**：[2, 3, 4, 5a, 5b]

**稳定性观察**：5a 和 5b 的相对顺序保持不变（5a 在 5b 之前），但这只是特定输入的结果。在其他情况下，顺序可能改变。

### 验证方法

你可以通过以下代码验证你的答案：

```cpp
void swap(int& a, int& b) {
    int temp = a;
    a = b;
    b = temp;
}

int partition(int arr[], int low, int high) {
    int pivot = arr[high];
    int i = low;
    for (int j = low; j < high; j++) {
        if (arr[j] <= pivot) {
            swap(arr[i], arr[j]);
            i++;
        }
    }
    swap(arr[i], arr[high]);
    return i;
}
```

注意：这是 Lomuto 分区方案，与本文使用的左右指针交换法略有不同，但核心思想一致。
