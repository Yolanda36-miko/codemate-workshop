# 常见排序算法复杂度与稳定性对比

## 适用对象
需要系统对比排序算法特性以做出合理选择的场景：复习备考、刷题训练、工程选型。

## 综合对比表

| 算法 | 最好时间 | 平均时间 | 最坏时间 | 空间 | 稳定性 | 原地 | 适用场景 |
|------|---------|---------|---------|------|--------|------|---------|
| 冒泡排序 | O(n) | O(n^2) | O(n^2) | O(1) | 稳定 | 是 | 教学演示 |
| 选择排序 | O(n^2) | O(n^2) | O(n^2) | O(1) | 不稳定 | 是 | 小数据、写操作昂贵 |
| 插入排序 | O(n) | O(n^2) | O(n^2) | O(1) | 稳定 | 是 | 小数据、基本有序 |
| 希尔排序 | O(n log n) | O(n^1.3) | O(n^2) | O(1) | 不稳定 | 是 | 中等数据 |
| 归并排序 | O(n log n) | O(n log n) | O(n log n) | O(n) | 稳定 | 否 | 稳定需求、链表排序 |
| 快速排序 | O(n log n) | O(n log n) | O(n^2) | O(log n) | 不稳定 | 是 | 通用首选（实际最快） |
| 堆排序 | O(n log n) | O(n log n) | O(n log n) | O(1) | 不稳定 | 是 | 内存受限 |
| 计数排序 | O(n+k) | O(n+k) | O(n+k) | O(k) | 稳定 | 否 | 整数、范围小 |
| 基数排序 | O(d·(n+k)) | O(d·(n+k)) | O(d·(n+k)) | O(n+k) | 稳定 | 否 | 定长整数/字符串 |
| 桶排序 | O(n+k) | O(n) | O(n^2) | O(n+k) | 稳定 | 否 | 均匀分布数据 |

> n = 元素数，k = 值域范围，d = 数字位数

## 各算法核心特点

### 冒泡排序
- **原理**：相邻元素两两比较交换，每轮将最大值"浮"到末尾
- **优点**：实现极简，稳定，可以提前终止
- **缺点**：O(n^2)，仅适合教学
- **最佳场景**：数据量 < 20 且已基本有序

### 选择排序
- **原理**：每轮从未排序部分选出最小值放到已排序末尾
- **优点**：交换次数最少（每轮至多 1 次）
- **缺点**：不稳定，无论数据是否有序都是 O(n^2)
- **最佳场景**：写操作昂贵（如 Flash 存储）

### 插入排序
- **原理**：将未排序元素逐个插入已排序部分的正确位置
- **优点**：对基本有序数据接近 O(n)，稳定，在线算法
- **缺点**：O(n^2)，移动元素开销大
- **最佳场景**：数据量 < 50，或基本有序（如 TimSort 的底层）

### 希尔排序
- **原理**：插入排序的改进，按增量序列分组排序
- **优点**：中等规模高效，原地
- **缺点**：不稳定，增量序列选择影响性能
- **最佳场景**：n < 10000，不允许额外空间

### 归并排序
- **原理**：分治——递归分割到单个元素，再两两合并
- **优点**：稳定，最坏情况也是 O(n log n)，适合链表
- **缺点**：需要 O(n) 额外空间
- **最佳场景**：需要稳定性 + 保证 O(n log n)（如 Java 对象排序）

### 快速排序
- **原理**：分治——选 pivot 分区，递归排序子区间
- **优点**：实际最快（缓存友好，常数因子小），原地
- **缺点**：不稳定，最坏 O(n^2)（可通过随机 pivot 规避）
- **最佳场景**：不需要稳定性的通用排序（C 标准库 qsort）

### 堆排序
- **原理**：建最大堆 → 反复取堆顶（最大值）+ 调整
- **优点**：O(n log n) 保证，O(1) 额外空间
- **缺点**：不稳定，实际比快排慢（缓存不友好）
- **最佳场景**：内存极度受限 + 需要 O(n log n) 保证

### 计数排序
- **原理**：统计每个值出现的次数，按顺序输出
- **优点**：O(n+k)，稳定
- **缺点**：仅适用于整数，值域 k 不能太大
- **最佳场景**：0-100 的分数排序，ASCII 字符排序

## 场景选型决策图

```
需要稳定排序？
├── 是 → 数据量？
│   ├── 小（n < 50）→ 插入排序
│   └── 大 → 内存充足？
│       ├── 是 → 归并排序
│       └── 否 → TimSort（混合算法，Python/Java 默认）
└── 否 → 内存充足？
    ├── 是 → 快速排序（通用最优）
    └── 否 → 堆排序（O(1) 额外空间）
```

## 排序算法的稳定性和原地性总结

```
稳定 + 原地：冒泡、插入
稳定 + 非原地：归并、计数、基数、桶
不稳定 + 原地：选择、希尔、快速、堆
不稳定 + 非原地：（较少见）
```

## Python 内置排序参考

```python
# list.sort() 和 sorted() 使用 TimSort
# - 时间复杂度：O(n log n) 最坏，O(n) 最好（已有序）
# - 空间复杂度：O(n)
# - 稳定性：稳定

arr = [3, 1, 4, 1, 5, 9, 2, 6]
arr.sort()              # 原地排序
sorted_arr = sorted(arr) # 返回新列表
sorted_arr_desc = sorted(arr, reverse=True)
sorted_by_key = sorted([(1,3),(2,1),(3,2)], key=lambda x: x[1])
```

## 查找算法补充

| 算法 | 平均时间 | 最坏时间 | 前提条件 | 适用场景 |
|------|---------|---------|---------|---------|
| 线性查找 | O(n) | O(n) | 无 | 无序小数据 |
| 二分查找 | O(log n) | O(log n) | 有序数组 | 有序大数据 |
| 哈希查找 | O(1) | O(n) | 哈希函数 | 键值查找 |
| BST 查找 | O(log n) | O(n) | BST 性质 | 动态数据 |
