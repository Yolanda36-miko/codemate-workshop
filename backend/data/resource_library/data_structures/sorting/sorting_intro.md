## 核心概念

### 什么是排序
排序是将一组数据按照特定顺序（如升序、降序）重新排列的过程。排序是计算机科学中最基础也是最重要的算法之一。

### 排序的稳定性
**稳定排序**：如果两个元素的值相等，排序后它们的相对顺序保持不变。
**不稳定排序**：相等元素的相对顺序可能改变。

稳定性在某些场景下很重要，例如对已经按某关键字排序的数据再按另一关键字排序时。

### 时间复杂度
时间复杂度描述算法执行所需的时间与输入规模的关系。对于排序算法，通常用大O表示法：
- **O(n^2)**：比较次数与 n 的平方成正比（基础排序算法）
- **O(n log n)**：比较次数与 n log n 成正比（高效排序算法）

## 常见排序算法

### 1. 冒泡排序（Bubble Sort）

**原理**：重复遍历数组，比较相邻元素，如果顺序错误就交换它们。

**过程**：
1. 从第一个元素开始，依次比较相邻的两个元素
2. 如果前一个大于后一个，交换它们
3. 重复上述过程，直到没有交换发生

**代码示例**：
```python
def bubble_sort(arr):
    n = len(arr)
    # 外层循环：控制排序轮数，最多需要 n-1 轮
    for i in range(n - 1):
        swapped = False  # 标记本轮是否发生交换
        # 内层循环：每轮比较次数递减，末尾 i 个元素已排好
        for j in range(n - 1 - i):
            if arr[j] > arr[j + 1]:
                # 交换相邻元素
                arr[j], arr[j + 1] = arr[j + 1], arr[j]
                swapped = True
        # 如果没有发生交换，说明数组已有序，提前终止
        if not swapped:
            break
    return arr

# 测试
arr = [64, 34, 25, 12, 22, 11, 90]
print(bubble_sort(arr))  # 输出: [11, 12, 22, 25, 34, 64, 90]
```

### 2. 选择排序（Selection Sort）

**原理**：每次从未排序部分选出最小（或最大）的元素，放到已排序部分的末尾。

### 3. 插入排序（Insertion Sort）

**原理**：将未排序元素逐个插入到已排序部分的正确位置。

### 4. 归并排序（Merge Sort）

**原理**：采用分治策略，将数组分成两半分别排序，然后合并结果。
**时间复杂度**：O(n log n)
**空间复杂度**：O(n)
**稳定性**：稳定

### 5. 快速排序（Quick Sort）

**原理**：选择一个基准元素，将数组分成两部分，使得左边都小于基准，右边都大于基准，然后递归排序。
**平均时间复杂度**：O(n log n)
**最坏时间复杂度**：O(n^2)
**空间复杂度**：O(log n)
**稳定性**：不稳定

## 复杂度对比

| 算法 | 最好时间 | 平均时间 | 最坏时间 | 空间复杂度 | 是否稳定 |
|------|----------|----------|----------|------------|----------|
| 冒泡排序 | O(n) | O(n^2) | O(n^2) | O(1) | 是 |
| 选择排序 | O(n^2) | O(n^2) | O(n^2) | O(1) | 否 |
| 插入排序 | O(n) | O(n^2) | O(n^2) | O(1) | 是 |
| 归并排序 | O(n log n) | O(n log n) | O(n log n) | O(n) | 是 |
| 快速排序 | O(n log n) | O(n log n) | O(n^2) | O(log n) | 否 |

## 常见错误

### 错误 1：循环边界错误
```python
# 错误：内层循环范围不对
def bad_bubble_sort(arr):
    n = len(arr)
    for i in range(n):  # 应该是 range(n-1)
        for j in range(n):  # 应该是 range(n-1-i)
            if arr[j] > arr[j+1]:  # 会索引越界！
                arr[j], arr[j+1] = arr[j+1], arr[j]
```
