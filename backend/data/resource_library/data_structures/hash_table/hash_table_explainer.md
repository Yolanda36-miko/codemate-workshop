# 散列表概念讲解

## 适合对象
学习散列表/哈希表的学生，需要理解哈希原理和冲突解决。

## 核心概念

### 哈希表原理
- 通过哈希函数将键映射到数组索引，实现 O(1) 平均查找。
- 核心组成：哈希函数 + 存储数组 + 冲突解决策略。

### 哈希函数设计
- 要求：计算快、分布均匀、确定性（相同键→相同值）。
- 常见方法：取模法、乘法哈希、多项式哈希（字符串）。

### 冲突解决
- **链地址法**：每个槽位存链表，冲突时追加节点。
- **开放定址法**：冲突时按某种探查序列找下一个空位。
  - 线性探查、二次探查、双重哈希。

### 性能与负载因子
- 负载因子 = 元素数 / 槽位数。
- 超过阈值（通常 0.75）时触发 rehash（扩容+重新哈希）。

### 易错点
1. 哈希函数设计不当导致大量冲突。
2. 开放定址的删除问题（需用惰性删除标记）。
3. rehash 时机选择和性能代价。
