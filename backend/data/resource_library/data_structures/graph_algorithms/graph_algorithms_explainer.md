# 图结构与图算法讲解

## 适合对象
学习图算法的学生，需要理解图的存储、遍历和经典算法。

## 核心概念

### 图的存储
- **邻接矩阵**：二维数组，O(1) 查询边是否存在，O(V²) 空间。
- **邻接表**：数组+链表/动态数组，O(V+E) 空间，适合稀疏图。

### DFS 与 BFS
- **DFS（深度优先）**：递归/栈实现，适合连通性检测、拓扑排序、回溯。
- **BFS（广度优先）**：队列实现，适合最短路径（无权图）、层次遍历。
- 选择依据：求最短路径用 BFS，遍历所有路径/回溯用 DFS。

### 经典算法
- **Dijkstra**：单源最短路径，贪心策略，适用于非负权图。
- **拓扑排序**：有向无环图的线性排序，DFS 或入度表实现。
- **最小生成树**：Prim（加点）和 Kruskal（加边）算法。

### 易错点
1. DFS/BFS 的适用场景混淆。
2. 邻接矩阵与邻接表的选择（稀疏图用邻接表）。
3. 拓扑排序需要检测环（合法性判断）。
