# BFS 和 DFS 图解讲解

## 核心概念

### BFS（广度优先搜索）

广度优先搜索（Breadth-First Search）是一种**按层访问**的图遍历算法。它从起始节点出发，先访问所有距离起点最近的节点（第一层），再访问距离次近的节点（第二层），以此类推。

**核心数据结构**：队列（Queue），遵循"先进先出"（FIFO）原则。

### DFS（深度优先搜索）

深度优先搜索（Depth-First Search）是一种**沿路径深入**的图遍历算法。它从起始节点出发，沿着一条路径尽可能深地探索，直到无法继续再回溯到上一个节点，尝试其他路径。

**核心数据结构**：递归调用栈或显式栈（Stack），遵循"后进先出"（LIFO）原则。

### 共同要求

两种算法都需要一个 **visited 数组**（或标记集合）来记录哪些节点已经被访问过，避免重复访问导致死循环或无限递归。

## 过程拆解

### BFS 过程

1. **初始化**：创建队列，将起始节点入队，并标记为已访问。
2. **循环处理**：
   - 从队列中取出队首节点。
   - 访问该节点（记录访问顺序）。
   - 遍历该节点的所有邻居。
   - 对于每个未访问的邻居，将其标记为已访问并加入队列。
3. **终止条件**：队列为空时，遍历完成。

**特点**：按层展开，先访问距离起始节点近的节点。

### DFS 过程（递归版）

1. **初始化**：标记起始节点为已访问。
2. **递归访问**：
   - 访问当前节点（记录访问顺序）。
   - 对于每个未访问的邻居，递归调用 DFS。
3. **回溯**：当所有邻居都访问完毕后，返回上一层。
4. **终止条件**：所有可达节点都被访问。

**特点**：沿路径深入，直到无法继续才回溯。

### 访问顺序对比

| 特性 | BFS | DFS |
|------|-----|-----|
| 顺序 | 按层访问 | 沿路径深入 |
| 数据结构 | 队列 | 栈/递归栈 |
| 空间复杂度 | O(n)（最坏情况） | O(n)（最坏情况） |
| 最短路径 | 天然支持 | 需要额外处理 |

## 小规模具体例子

### BFS 访问序列

**序列**：0 → 1 → 2 → 3 → 4

**逐条解释**：

1. **0**：从起始节点开始，首先访问根节点 0。
2. **1**：访问 0 的第一层邻居（距离为 1），先访问邻居 1。
3. **2**：接着访问 0 的另一个第一层邻居 2。
4. **3**：现在访问第二层节点（距离为 2），先访问 1 的邻居 3。
5. **4**：接着访问 1 的另一个第二层邻居 4。

**特点**：BFS 像水波一样向外扩散，先访问完所有距离为 1 的节点，再访问距离为 2 的节点。

### DFS 访问序列

**序列**：0 → 1 → 3 → 4 → 2

**逐条解释**：

1. **0**：从起始节点开始，首先访问根节点 0。
2. **1**：沿着第一条路径深入，访问 0 的邻居 1。
3. **3**：继续深入，访问 1 的邻居 3。
4. **4**：3 没有未访问的邻居，回溯到 1，访问 1 的另一个邻居 4。
5. **2**：4 没有未访问的邻居，回溯到 1；1 的邻居都访问完，回溯到 0；最后访问 0 的另一个邻居 2。

**特点**：DFS 沿着一条路径走到尽头，然后回溯探索其他分支。

### 顺序差异原因

- **BFS**：使用队列，邻居按顺序入队，保证同一层的节点先被处理。
- **DFS**：使用栈，最后入栈的邻居最先被处理，导致沿路径深入。

## 易错提醒

### 错误一：忘记标记 visited

**后果**：对于有环的图，会导致无限循环或重复访问。

**错误示例**：
```python
def bfs(node):
    queue = [node]
    while queue:
        current = queue.pop(0)
        print(current)
        for neighbor in adj[current]:
            queue.append(neighbor)  # 没有检查是否已访问
```

**正确做法**：在入队（或访问）时标记 visited。

### 错误二：BFS 在出队时标记 visited

**后果**：同一节点可能被多次入队，导致队列中出现重复节点，降低效率甚至内存溢出。

**错误示例**：
```python
def bfs(node):
    queue = [node]
    visited = set()
    while queue:
        current = queue.pop(0)
        visited.add(current)  # 出队时才标记
        for neighbor in adj[current]:
            if neighbor not in visited:
                queue.append(neighbor)
```

**正确做法**：在入队时就标记 visited。

### 错误三：DFS 缺少递归终止条件

**后果**：对于无限图或有环的图，会导致递归深度过大而栈溢出。

**正确做法**：在递归函数开头检查节点是否已访问。

### 错误四：非连通图只从一个节点出发

**后果**：会漏掉未连通部分的节点。

**正确做法**：遍历所有节点，如果节点未被访问，则从该节点发起遍历。

## 小练习

### 练习题目

请手动写出以下图的 BFS 和 DFS 访问序列（从节点 A 开始）：

**图描述**：4个节点，边为：A-B、A-C、B-D

**邻接表表示**：
```
A: [B, C]
B: [A, D]
C: [A]
D: [B]
```

**图结构**：
```
    A
   / \
  B   C
 /
D
```

### 答案检查方式

**BFS 答案**：A → B → C → D

**验证方法**：
1. A 入队，访问 A → 序列 [A]
2. B、C 入队 → 队列 [B, C]
3. B 出队，访问 B → 序列 [A, B]
4. D 入队 → 队列 [C, D]
5. C 出队，访问 C → 序列 [A, B, C]
6. D 出队，访问 D → 序列 [A, B, C, D]

**DFS 答案**（一种可能）：A → B → D → C

**验证方法**：
1. 访问 A，递归进入 B → 序列 [A, B]
2. 访问 B，递归进入 D → 序列 [A, B, D]
3. D 无未访问邻居，回溯到 B
4. B 无未访问邻居，回溯到 A
5. 递归进入 C，访问 C → 序列 [A, B, D, C]

### 注意

DFS 的结果可能因邻接表顺序不同而不同。如果邻接表中 A 的邻居顺序是 [C, B]，则 DFS 序列可能是：A → C → B → D。
