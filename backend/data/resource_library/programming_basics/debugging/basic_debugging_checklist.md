# 调试检查清单

遇到 bug 时，按照以下顺序依次检查：

---

## 一、检查语法错误

### 1.1 基本语法检查
- [ ] 检查所有语句末尾是否有冒号 `:`（if、for、while、def、class）
- [ ] 检查引号是否配对（单引号/双引号/三引号）
- [ ] 检查括号是否配对（圆括号、方括号、花括号）
- [ ] 检查缩进是否一致（统一使用 4 空格或 Tab）

### 1.2 变量和函数名
- [ ] 检查变量名是否拼写正确
- [ ] 检查函数名是否拼写正确
- [ ] 检查是否使用了 Python 关键字作为变量名

---

## 二、检查运行时错误

### 2.1 错误信息分析
- [ ] 读取错误类型（SyntaxError、IndexError、TypeError 等）
- [ ] 定位错误发生的行号
- [ ] 阅读错误描述，理解问题原因

### 2.2 常见运行时问题
- [ ] **NameError**：变量未定义 → 检查变量是否在使用前已赋值
- [ ] **IndexError**：列表索引越界 → 检查索引范围是否正确
- [ ] **KeyError**：字典键不存在 → 检查键名拼写或使用 get() 方法
- [ ] **TypeError**：类型不匹配 → 检查操作数类型是否正确
- [ ] **ZeroDivisionError**：除零错误 → 检查除数是否可能为零

---

## 三、检查逻辑错误

### 3.1 输出验证
- [ ] 检查输入值是否符合预期
- [ ] 在关键位置添加 print 语句输出变量值
- [ ] 验证中间结果是否正确

### 3.2 边界条件检查
- [ ] 检查空列表/空字符串处理
- [ ] 检查零值、负值、极值输入
- [ ] 检查循环边界（循环次数是否正确）

### 3.3 逻辑流程检查
- [ ] 验证条件判断是否正确
- [ ] 检查循环是否提前退出或无限循环
- [ ] 确认函数返回值是否正确

---

## 四、调试步骤建议

### 步骤 1：复现问题
- 确保能够稳定地复现 bug
- 记录复现所需的输入和操作步骤

### 步骤 2：缩小范围
- 通过注释代码块逐步定位问题区域
- 使用二分法快速缩小可疑代码范围

### 步骤 3：添加调试信息
- 在关键位置添加 print 语句
- 输出变量值、函数调用参数、返回值

### 步骤 4：验证假设
- 根据调试信息提出假设
- 通过修改代码验证假设是否正确

### 步骤 5：修复并测试
- 修复发现的问题
- 使用多种测试用例验证修复是否有效

---

## 五、常用调试技巧

1. **分段测试**：将复杂代码分成小块，逐段测试
2. **对比验证**：与已知正确的代码或结果进行对比
3. **静态检查**：使用代码检查工具（如 pylint、flake8）
4. **版本对比**：如果代码之前正常，对比最近的更改
5. **寻求帮助**：将问题描述清楚，向同学或老师请教

---

## 六、预防性措施

- [ ] 编写代码时保持小步调试，每写一部分就测试
- [ ] 使用有意义的变量名和函数名
- [ ] 添加适当的注释说明复杂逻辑
- [ ] 编写测试用例覆盖各种情况
- [ ] 使用版本控制记录代码变更
