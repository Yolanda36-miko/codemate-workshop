## 核心概念
函数是一段可重用的代码块，通过函数名调用执行。调用函数时，程序会跳转到函数体执行，执行完后再返回调用点继续。

## 分步骤讲解
1. 定义函数：使用 def 关键字，后跟函数名和参数列表。
2. 调用函数：使用函数名加括号，传入实际参数。
3. 参数传递：Python 中的参数是引用传递，但不可变对象（int, str）修改不影响外部，可变对象（list, dict）修改会影响外部。
4. 返回值：使用 return 语句返回结果；没有 return 的函数返回 None。

## 代码示例
```python
def add(a, b):
    return a + b

result = add(3, 5)
print(result)  # 输出 8

def modify_list(lst):
    lst.append(4)

my_list = [1, 2, 3]
modify_list(my_list)
print(my_list)  # 输出 [1, 2, 3, 4]
```

## 常见错误
- 忘记写冒号或缩进
- 函数内部修改不可变对象期望影响外部变量
- 忘记 return 导致返回 None
