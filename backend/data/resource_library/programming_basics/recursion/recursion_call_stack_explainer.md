## 核心概念

### 什么是递归
递归是一种编程技巧，指函数直接或间接调用自身。递归函数必须包含：
1. **出口条件（base case）**：终止递归的条件，避免无限循环
2. **递推关系（recursive case）**：将问题分解为更小的子问题

### 调用栈与栈帧
每次函数调用时，系统会在**调用栈**中创建一个**栈帧**，存储：
- 函数的参数
- 局部变量
- 返回地址（调用结束后回到哪里）

递归深度越深，调用栈越高，可能导致**栈溢出**（Stack Overflow）。

### 递推与回归
- **递推**：从原问题逐步分解到出口条件
- **回归**：从出口条件逐步返回结果到原问题

## 代码示例：阶乘

```python
def factorial(n):
    # 出口条件：n=0 或 n=1 时返回 1
    if n == 0 or n == 1:
        return 1
    # 递推关系：n! = n * (n-1)!
    return n * factorial(n - 1)

print(factorial(5))  # 输出: 120
```

### 执行过程
```
factorial(5)
  -> 5 * factorial(4)
       -> 4 * factorial(3)
            -> 3 * factorial(2)
                 -> 2 * factorial(1)
                      -> 返回 1
                 <- 2 * 1 = 2
            <- 3 * 2 = 6
       <- 4 * 6 = 24
  <- 5 * 24 = 120
返回 120
```

## 常见错误

### 缺少出口条件
```python
def bad_factorial(n):
    return n * bad_factorial(n - 1)  # 无限递归 -> 栈溢出
```

### 递归深度过大
Python 默认递归深度限制约为 1000，超过会引发 `RecursionError`。

### 出口条件错误
```python
def wrong_factorial(n):
    if n == 0:
        return 0  # 错误：0! 应该是 1
    return n * wrong_factorial(n - 1)
```
