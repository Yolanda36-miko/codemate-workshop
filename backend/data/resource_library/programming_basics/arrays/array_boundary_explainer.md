# 数组边界：下标从0开始与越界错误

## 适用对象
正在学习数组（列表）操作，经常出现 IndexError 的学生。

## 学习目标
- 理解数组下标从0开始的规则
- 掌握数组最后一个元素的下标是 n-1
- 识别常见的索引越界错误场景
- 学会安全地访问数组元素

## 核心概念
数组是连续存储的线性结构，每个元素有唯一的下标（索引）。在 Python 中，列表的下标从0开始，第一个元素下标为0，最后一个元素下标为 len(arr)-1。访问小于0或大于等于 len(arr) 的下标会引发 IndexError。

## 分步骤讲解
1. 下标计算：如果数组有 n 个元素，有效下标范围是 0 到 n-1。
2. 常见越界：循环中 i <= n 时访问 arr[i] 会越界。
3. 负数下标：Python 支持负数下标，-1 表示最后一个元素，-n 表示第一个元素，但 - (n+1) 会越界。

## 代码示例
```python
arr = [10, 20, 30, 40]
print(arr[0])   # 10
print(arr[3])   # 40
print(arr[-1])  # 40
# print(arr[4]) # IndexError: list index out of range

# 安全遍历
for i in range(len(arr)):
    print(arr[i])
```

## 常见错误
- 循环条件写成 i <= len(arr) 导致最后一次越界
- 忘记空数组特例：if arr: 再访问 arr[0]
