## 资源生成规则

### 1. 输出数量与类型
严格按 resource_types 列表生成资源卡片，每个类型生成 1 个卡片。如果 resource_types 包含 3 种类型，就生成恰好 3 个卡片。

### 2. 标题要求
- 每个标题必须包含具体主题名称，格式为"{主题} — {资源类型}"
- 禁止使用泛泛的标题如"递归讲解"
- 示例正确标题："递归调用栈 — 图解讲解"、"二叉树遍历 — 代码示例"

### 3. 摘要要求
- summary 字段用 1-2 句话说明该资源的用途和特色
- 必须体现与基础水平和学习目标的关联

### 4. 按资源类型生成结构化 sections

**图解讲解** — 必须包含以下 section kinds：
- highlight: 核心要点提炼
- steps: 分步骤拆解（用 steps 数组）
- compare: 与相关概念的对比分析
- complexity: 时间/空间复杂度分析
- 可选 code: 关键代码片段（语言必须为 {{ language }}）

**代码示例** — 必须包含以下 section kinds：
- highlight: 代码整体说明
- code: 完整可运行代码（language 字段必须为 "{{ language }}"，不能是其他语言）
- steps: 代码阅读指南（用 steps 数组）

**易错点** — 必须包含以下 section kinds：
- warning: 常见错误描述
- compare: 错误写法 vs 正确写法的对比
- code: 正确写法参考（language 必须为 "{{ language }}"）

**分层练习** — 必须包含以下 section kinds：
- practice: 基础层练习（至少 2 题）
- practice: 进阶层练习（至少 2 题）
- practice: 提高层练习（至少 1 题）
- answer_hint: 提示与参考答案

**项目案例** — 必须包含以下 section kinds：
- task: 项目概述与目标
- steps: 分阶段实现步骤
- code: 核心代码框架（language 必须为 "{{ language }}"）
- text: 测试与优化建议

### 5. 编程语言严格约束
- 所有 section 中的 language 字段必须为 "{{ language }}"
- 所有 codeBlock 或 code section 中的代码必须是 {{ language }} 语法
- 如果 {{ language }} 是 "C"，代码必须是标准 C 语法（printf, malloc），不能出现 C++ 语法
- 如果 {{ language }} 是 "C++"，可以使用 cout、vector、STL

### 6. 个性化匹配
- 如果基础水平为"基础薄弱"，内容应多包含基础概念解释和详细步骤
- 如果基础水平为"较好"，内容可更侧重进阶技巧和综合应用
- 如果学习目标为"考试复习"，侧重考点归纳和易错分析
- 如果学习目标为"刷题训练"，侧重代码示例和练习题
- 如果学习目标为"项目实践"，侧重项目案例和综合应用
- 如果当前困难点有具体内容，在对应资源中重点覆盖这些薄弱点

### 7. 语言要求
所有文本内容使用简体中文，代码中的变量名可使用英文。

## 输出格式（严格遵守）
直接输出一个 JSON 对象，不要用 markdown 代码块包裹，不要添加任何说明文字：

{
  "resource_cards": [
    {
      "id": "资源唯一标识",
      "title": "资源标题（含主题和类型）",
      "type": "图解讲解",
      "summary": "简短摘要说明资源用途和个性化特色",
      "sections": [
        {"kind": "highlight", "heading": "标题", "content": "内容"},
        {"kind": "steps", "heading": "标题", "steps": ["步骤1", "步骤2"]},
        {"kind": "code", "heading": "标题", "content": "代码内容", "language": "{{ language }}"}
      ],
      "key_concepts": ["概念1", "概念2"],
      "learning_tips": ["学习建议1", "学习建议2"],
      "recommended_usage": "推荐使用方法说明",
      "estimated_time": "预计学习时间",
      "match_reason": "为什么推荐这个资源给当前学生",
      "personalized_reason": "个性化匹配的详细说明"
    }
  ]
}

## 字段说明
- id: 唯一标识符，格式为 "res-llm-001", "res-llm-002" 等
- title: 必填，字符串
- type: 必填，必须是 resource_types 中的值之一
- summary: 必填，1-2 句话
- sections: 必填，数组，每个元素有 kind/heading/content 等字段
- key_concepts: 可选，字符串数组
- learning_tips: 可选，字符串数组
- recommended_usage: 可选，字符串
- estimated_time: 可选，如 "20 分钟"、"45 分钟"
- match_reason: 必填，个性化匹配原因
- personalized_reason: 必填，详细的个性化推荐说明

重要：
- 只输出 JSON 对象本身，不要用 ```json 包裹
- 不要输出任何解释、说明、前缀或后缀文字
- resource_cards 数组的长度必须等于 resource_types 的长度
- 所有代码的 language 字段必须是 "{{ language }}"
